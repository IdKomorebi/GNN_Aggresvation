## 2. 系统侧相对论文的算法改进清单

按"能否作为论文主张"分三级。所有数字来自仓库内实测记录。

### A 级 · 足以支撑论文贡献点

| 改进 | 机制 | 实测效果 | 出处 |
| --- | --- | --- | --- |
| **A1 动作条件集合函数** | 8 个处置动作，条件编码用动作族 one-hot + 归一化强度（5+1 维），新增同族档位不扩维；查询空间 8^32≈7.9e28 | 盲测 45 方案 / 75 次重训，加权 MAE 0.0470，Spearman 0.86–0.93 | `treatments.py`、`treatment_oracle.py` |
| **A2 读出层列空间增广** | 闭式岭回归特征由 φ 扩成 φ⊕x⊕x²，强制列空间包含"已发布字段上的线性回归" | MAE 0.1109 → **0.0434**；最危险低估 −0.269 → **−0.097**；排序相关 0.815 → 0.960 | `V3/logs/20260901_02`、`03` |
| **A3 取最大式双主干** | 两个独立种子主干各解一次读出取 max。反证：把最强的拼接读出也放进 max 反而全面变差 → **赢的是成员多样性，不是"取上界"** | 危险误判 2.31% → **1.22%**；保守误判 1.63% → 1.77%；0/8 目标变差 | `sampling_lab/ROUND8.md` |
| **A4 形态校正 + 跨电网迁移** | 残差随方案形态系统变化：加噪越多越高估、动作种类越杂越低估——是**训练方式**的性质而非数据的性质，故可迁移 | PJM 留一 2.54% → 1.22%；RTS+CAISO 原封不动用 2.64% → **0.90%**；本地重拟合反而更差 1.69% | `ROUND9/10`、`V8/backend/app/config.py` |
| **A5 信息单调上包络** | 子节点风险取 `max(自身估计, 父节点风险)`——攻击者可忽略新字段，风险不可能下降 | 实例：快速模型估 0.5552，父节点已 0.6440，真重训 **0.7332**，被包络挡住 | `logs/20260831_04` |
| **A6 保守程度对照协议** | 给每个臂加一系列偏移，画 (保守误判, 危险误判) 曲线，在**相同保守误判水平**上横比 | 一轮内推翻三个"看着很好"的结论（异质采样 −68%、场景A 校正 −37%、maxall −70%），全是"只是更保守" | `match_control.py` |
| **A7 盲测分布必须来自搜索** | 预设规则集没有覆盖"少量原值字段 + 中等处置"，而那是误差最大的区域 | 盲测报告最大低估 0.15；搜索实际走到的区域 **0.30** | `logs/20260831_05` |
| **A8 闭式读出进搜索回路** | 论文只把闭式读出用于估计器评测；系统把 5000+ 次路径查询全换成闭式读出 | 真重训预算 **5 次 → 1 次**；误差散布 0.15–0.30 → **0.06–0.09** | `logs/20260831_05` |
| **A9 随机机制的最坏实现口径** | 含噪方案风险必须是多份噪声实现上的**最大**攻击 R²，训练/查询/终判三处对齐 | 口径修正；查询期 3 份实现取最大 | `treatment_oracle.py` |

### B 级 · 实现细节，写进方法节或附录

- **特征截断 ±8σ**：兜底触发率 1.85%–3.29% → **0.08%**；最危险低估 场景B −0.2968 → −0.1388。
- **H/B 分层**：逐轮 D-Gating 剥离互不相交的推断源，`H=∪P_r` 可处置，`B` 锁定；决策空间 `K^n → K^|H|`。
- **R/T/S 结构化搜索**：H 切成 R 原样 / T 统一动作 / S 屏蔽，两阶段贪心。
- **关系剥离前置层**：恒等式、业务公式、相对残差 <0.10 的近似关系先剥离——**电力领域独有，审稿人会喜欢**。
- **效用度量**：字段保真度 = 0.7·corr² + 0.3·(1−|方差比−1|)。

### C 级 · 否定结果（单独成一节，这是可信度的来源）

| 尝试 | 结果 | 说明什么 |
| --- | --- | --- |
| 非线性 MLP 读出头 | 8/8 个目标-场景组合更差 | 读出层的**模型类不是瓶颈** |
| 主干多训 140→300 轮 | 低估>0.1 从 3.04% 涨到 10.36%，胜率 32% | 主干会过拟合**它自己那套方案采样分布** |
| 按重要性加权抽字段 | 96 个配对单元上改善≈0，3 个目标最危险低估坏 1.6–22× | "多数小赢、少数大输"，安全性取决于尾部 |
| 调方案形态采样比例 | 对照下全部是"只是更保守" | **训练分布是零和的盘子** |
| 三主干 | 与双主干打平，训练 3×（424s vs 50s） | 多样性收益在第二个主干就饱和 |
| 门控强度当重要性 | 在自己的主场方案族上反而最差 | 门控答的是"最小充分集"，不是"单字段信息量" |

> **可以直接当一句论断写进论文**：凡是想"让单个估计更准"的改动全部失败；
> 凡是"承认单个估计会错，再用多个独立估计取上界、或按方案形态修正去兜"的改动都成功了。
> 这句话有 8 条实验背书。

## 3. 先验技术地图与创新性判定

### core 的精确形状

`v_c(S)` = 攻击者拿到字段集合 S 的完整列数据后，**专门针对 S 重新训练**推断模型，对机密字段 c 所能达到的**最高**测试精度。

三个词是全部技术含量来源：**集合**（不是字段）、**重训**（不是遮蔽）、**最高**（不是平均）。
隐含性质：`v_c(S)` 在子集格上**单调不减**（攻击者可忽略多余字段）。

### 八个文献簇

| 文献簇 | 它有什么 | 差在哪 | 威胁度 |
| --- | --- | --- | --- |
| **SPVIM**（Williamson & Feng, ICML 2020） | **完全相同的重训语义**，还有渐近分布、置信区间 | 输出逐字段 Shapley 标量；只抽 Θ(n) 个子集；**没有任意 S 的 oracle**；不关心尾部 | 最高 |
| **Explaining by Removing**（Covert, Lundberg & Lee, JMLR 2021） | **掩码代理模型**，随机子集遮蔽训练，一次前向答任意 S；统一 26 种方法 | v(S) 语义是把特征从**固定模型**边缘化，不是重训 | 最高 |
| FastSHAP / ViT-Shapley（ICLR'22/'23） | 用网络摊销**归因值** | 摊销标量输出而非集合函数；固定模型语义；只报平均保真度 | 中高 |
| ROAR（Hooker 等, NeurIPS 2019） | 主张**只有重训才是忠实评测** | 只按归因序删 top-k，没有集合函数 | 低（**盟友**） |
| 高阶交互（Faith-Shap JMLR'23；SPEX ICML'25；ProxySPEX；shapiq） | 大规模高阶交互发现、稀疏傅里叶 | 刻画**模型行为**的交互，不是**数据可推断性**；不做重训认证 | 中高 |
| 偏信息分解 PID（Williams & Beer 2010） | 协同/冗余/唯一信息的**正式词汇** | 四变量以上估计不可行；没有格上搜索 | 低（借词汇） |
| 弱次模性（Das & Kempe；Khanna 等 AISTATS'17） | 次模比 γ 给贪心特征选择的乘性保证 | 全用于**挑好特征**，没人用于**审计危险组合** | 低（**空地**） |
| 格上边界计算（Gunopulos 等 PODS'97；单调对偶化） | 成员查询下枚举极大集合 | 假设 oracle **廉价且精确** | 低（**空地**） |
| 数据库推断问题（Farkas & Jajodia, SIGKDD Expl. 2002） | 安全领域正宗祖先：低密级组合推出高密级 | 依赖关系是逻辑/函数型且先验已知 | 中（不引会被说不懂历史） |
| IGNN（Hu, Nie, Zhou, …, Guan；**IEEE TSG 2026**，DOI 10.1109/TSG.2026.3667966） | 推断关系图 + AHP + 推断加权 GAT，**字段级**分数；IEEE 30/57、ACTIVSg200、case1354 | 字段级；固定模型的风险传播；仿真潮流数据 | 直接背景 |

### 最危险的一句话

审稿人最可能的攻击：「**这就是 Covert 的掩码代理模型换个应用场景**。」
一句话回答（有数据支撑）：**代理模型估的是遮蔽后固定模型的表现，我们估的是重训后的最优表现；
这两个量在协同上差 3.4 倍、排序相关仅 0.351——不是同一个被估量。**
这句话和对比图要放进**引言**，不要留到第 6 节。

### 真正无人占据的三条

1. **重训语义下的任意集合 oracle。** SPVIM 有语义没 oracle；Covert 有 oracle 没语义。
   交集之所以重要，是因为两种语义在唯一要紧的量上给出互相矛盾的答案。
2. **摊销误差的尾部集中现象及机制归因。** 整个摊销解释文献只报平均保真度。
   `v_c(S)` 是内层优化的**最优值**，摊销间隙在"逐实例最优离共享平均最远"处最大，强协同正属此类。
   这是对 FastSHAP 一类方法的**普适批评**，它们很难反驳（从没测过尾部）。
3. **把认证当作认识论装置。** 红线："重训真值只用于评估与认证，绝不进入查询、路由或校准路径"。
   最有力的演示：手工多项式字典在五阶报出 441 个强协同，认证后**无一为真**，与随机对照无统计差异。

### 必须主动降调的两条

- **闭式读出这个机制本身**。R2D2、MetaOptNet 已有，再往下就是"冻结主干 + 线性探针"。
  正确表述：**贡献不在这一层用了岭回归，而在于论证了摊销应该发生在哪个层次**。诊断是贡献，实现是推论。
- **"任意集合"这个说法**。保真度只在训练掩码分布有支撑处验证过，k≥6 失效即此。

> **把局限改写成贡献**：`k*=5` 不是"只做到五阶"，而是"**我们交付的不只是估计器，
> 还有它经过定标的可用边界**"。几乎没有估计方法的论文会给出自己的失效边界并逐层剥开成因
> （搜索端不是瓶颈 / 真值端受样本量限制 / 分布端在 k≥6 根本没有强尾）。

## 4. 放弃的两条路，为什么走不通（这是论文的论点，不是失败）

### 思路一 · 图上的敏感度扩散

扩散本质是**可加的、成对的**，而协同按定义**非可加**。更要命的是字段级扩散产生的数
**与"同时发布了哪些其他字段"无关**，而推断风险恰恰完全取决于这件事。
所以无论聚合公式怎么改（GNN1–13 试了十三种，74 号测出六种聚合跨度仅 **0.008**），
**都不可能表达出这个量**。不是调参失败，是表达力的上界。

### 思路二 · 训练时顺带给出敏感度

这条路其实走通了，而且结果比"没有好的想法"更有价值：它就是**共享读出的全摊销模型**。
实测全局排序相关 0.606 看似可用，但真值最强的 100 个协同上坍缩到 **0.130**。
**这个思路没有死，它变成了论文的负面诊断**，也正是创新点 2 的来源。

> 论文用法：写成第 4 节的两个"排除性对照"——(a) 字段级扩散在原理上无法表达集合属性
> （引 IGNN 作代表，配 74 号聚合消融）；(b) 训练时顺带输出的共享读出在尾部失明
> （配三个排除性对照：逐集合仿射校准、集成方差、跨种子一致）。
> **走过的弯路是这篇论文最难被别人复制的部分。**

## 5. 可解释性问题的答案

用户的困扰："考虑数据推断的敏感度评定本来就需要人为解释的部分，不然不太可能解释出来。"

**这是症状不是病因**：字段级敏感度分数难解释，是因为它试图给一个**不存在于字段层面的量**赋值。
0.73 分的字段，说不出为什么是 0.73，因为这个数在物理上没有指称。

到了集合级，解释**不需要额外机制，它就是结论本身**：

- **被认证的协同三元组即是解释**。「风电出力 ÷ 风电占比 = 总发电量」机制写在结论里。
- **关系剥离层本来就是符号化的**。产出是人可读的方程，不是分数。
- **逐轮剥离给出的是路径**。P₁、P₂… 每轮单独重训验证。

论文里可以明说：**把评估单位从字段升到集合，不是用可解释性换精度，而是同时拿回了两者。**

## 6. 交付物：从估计器到策略对象

「我们能快速估计任意集合的敏感度」是能力陈述，没有赌注。
必须交付**策略对象**：可发布域 `𝒮 = {S : v_c(S) ≤ τ}` 由单调性是**下闭的**，
完全由其**极大元**决定——那个反链就是**安全发布边界**。

**字段级分级只能表达一个"子立方体"**（被判公开的字段的全部子集）。
四字段例子：c、d 各自安全而 cd 越界 → 都判受限就丢掉 abc 和 abd 两个合法方案（过度保守），
都判公开就放行 cd（真实泄露）。**无论怎么贴标签都是错的，因为格式本身表达不了这个形状。**
引言里三句话讲完，无法反驳。

## 7. 搜索算法：怎么把这些东西搜出来

### ⚠️ 一处更正

讨论中曾写过「摊销查询是毫秒级，在总账上接近免费」。**这句话是错的。**
它只在查询次数是多项式时才成立。真要遍历全部子集，`2⁴⁴ ≈ 1.76e13` 次，
按最快的 0.4 毫秒一次算是 **223 年**。搜索空间是指数的，估计器再快也救不了。

**但真正的情况是：三样产出没有一样需要遍历这个格。**

### 产出一 · 一个大的安全发布面

- **做法**：从空集开始，每步在剩余字段里逐个试，加"仍安全且估计风险最低"的那个，加不动就停。
- **调用次数**：`n²` 量级 ≈ **2000 次估计 = 34 秒**。系统实测正在此量级（两阶段 437 / 6282 次）。
- **更好的面**：换几十个随机起始顺序，50 次重启 = 10 万次估计，不到半小时。
- **认证**：沿最终顺序**二分**（单调性保证风险沿链只增不减），44 字段只要 **6 次重训**。
- **要点**：指数空间从头到尾没被碰过。NP 难的是找*全局最大*的面，而我们不追求绝对最优。

### 产出二 · 极小危险组合清单

- **关键：方向反过来——从大往小缩。**
- **做法**：全集必然危险（池整体 0.99）。逐个尝试拿掉一个字段：仍危险就真拿掉，变安全就放回。
  走完一遍剩下的就是一条**极小危险组合**（缺任一即安全，凑齐即越界）。
- **调用次数**：一遍 44 次估计得一条。**500 条 ≈ 22000 次 ≈ 6 分钟**，完全不涉及枚举。
- **完整性**：证明不了"找全了"。做法是画**饱和曲线**（重启次数 vs 累计发现的不同组合数），
  曲线压平说明继续找收益很小。论文必须写成**经验性**完整度陈述。
- （若追求可证完整，对应 MUS 枚举框架 MARCO，*Constraints* 2016；
  收缩步可用 QuickXplain，AAAI 2004，把 44 次降到约 10 次。**第一篇论文不必走到这一步**。）

### 产出三 · 各阶强协同：束搜索

每阶只保留协同最强的 W 个，下一阶只从这 W 个各加一个字段生成。
**每阶代价固定为 `W × n`，与阶数无关**——组合增长压成线性增长。

| 阶 | 穷举 | 束搜索 W=5000 | 倍数 |
| --- | --- | --- | --- |
| 5 | 1 086 008 | 200 000 | 5× |
| 6 | 7 059 052 | 195 000 | 36× |
| 7 | 38 320 568 | 190 000 | 200× |
| 10 | 2 481 256 778 | 175 000 | 14000× |

#### 束搜索凭什么？——**没有证明**

**束搜索在这个问题上没有任何近似保证。** 它成立的前提是「层级性」：
强的 k 阶协同应含有一个排名靠前的 (k−1) 阶子集。这是 ProxySPEX 一类的通行假设，
**而 94 号实验恰好证伪了它的严格版本**：10 个真协同的最好四阶父集排名 **164–2429**，
B=100 全漏、B=1000 漏 4、B=5000 全覆盖。

换个读法：2429 落在 `C(44,4)=135751` 的**前 1.8%** → **层级性是弱的，但不是没有**，束搜索靠的是这个弱版本。

**但要看清这个标定的循环性**：`r(5)≤2429` 是拿*穷举五阶后认证出的那 10 个协同*量出来的。
没有穷举真值，根本无从知道束宽该取多少。**外推到六阶七阶是假设，不是证明**——论文必须这样写。

#### 能证的那一半：随机抽样给可证的漏检上界

> 在 k 阶集合里**均匀随机**抽 `m` 个，若一个都没超过阈值 θ，则以 95% 置信度，
> 超过 θ 的集合占比 `p ≤ 1 − 0.05^(1/m) ≈ 3/m`（三倍律）。

| 抽样数 m | 耗时 @0.4ms | 占比上界 | 五阶最多漏 | 七阶最多漏 |
| --- | --- | --- | --- | --- |
| 400 | 0.2 秒 | 0.75% | 8 145 | 287 000 |
| 10 000 | 4 秒 | 0.030% | 326 | 11 500 |
| **100 000** | **40 秒** | **0.0030%** | **33** | 1 150 |

现在用的是 m=400 的随机对照。**加到 10 万，结论强度提高两个数量级，代价 40 秒。**

该写的话：*「束搜索找到了 Y 个强协同；独立的 10 万次均匀抽样未发现任何遗漏样本，
因此以 95% 置信度，未被发现的强协同不超过 33 个。」*
**找到的部分是启发式的，没找到的部分是有界的**——不需要任何未经证明的层级性假设。

两点细节：(a) 这是对**估计器判定**的界，要 composition 到真值需在阈值上加已标定的保守余量，两步分开写；
(b) 若抽样中观察到 x 个超阈，换 Clopper–Pearson 上界即可，形式不变。

#### 附带一条免费的剪枝（重要）

因为风险值上限是 1，恒有

```
syn(S) ≤ 1 − max_{T⊊S} v(T)
```

右边**完全由已算过的低阶值决定，不需要任何新查询**。
要找协同 > 0.10，每个子集都必须低于 0.90；而「风险低于 0.90 的集合」这个族也是下闭的，可逐层剪。
**任何已有子集超过 0.90 的集合直接跳过。**

这条不等式还解释了「高阶没有强尾」：**随阶数上升风险逼近饱和，协同取值被从上方挤掉**。
衰减律（0.455 → 0.196 → 0.154）可能相当一部分是饱和造成的。
**建议实验**：用已缓存真值把每阶最强协同 `syn_max(k)` 与该阶头顶空间 `1 − v̄(k−1)` 画在一起。
平行 → 衰减律大部分是饱和效应（得到**解释**而非只是曲线）；明显更低 → 才是"真稀疏"的证据。

### 通用模型的价值 = 一个可以写下来的数

重训按一次 30 秒保守估计：

| 产出 | 估计调用 | 若每次都真重训 | 用估计器实际耗时 |
| --- | --- | --- | --- |
| 一个安全发布面 | ~2 000 | 约 17 小时 | 34 秒 + 6 次重训 |
| 500 条极小危险组合 | ~22 000 | 约 7.6 天 | 6 分钟 + 逐条认证 |
| 五阶强协同（W=5000） | ~200 000 | 约 69 天 | 80 秒 + 认证 top-40 |

> **通用模型不是让指数搜索变可行**——没有任何东西能做到，这三个算法也从来没打算走遍 2⁴⁴。
> 它做的是：**让本来就是多项式次的搜索，从"几十天"变成"几分钟"。**

**报告指标必须改**：从「每次查询快 22.4 倍」换成「**用几次重训认证了整条边界**」。
现成的数据点：换上闭式读出后真重训 **5 次 → 1 次**。

### 四条必须写明的边界

1. 得到的是「极大」不是「最大」——用多次重启的散布报告差距，或用次模比 γ 给数据相关保证。
2. 束搜索会漏（已实测 W=1000 时 10 个漏 4 个）——**必须报束宽与召回的关系曲线**。
3. 完整性只能是经验性的——但写清楚反而加分，因为字段级分级连这种经验完整度都提供不了。
4. 阈值 τ 一变，三样都要重来。

## 9. 【核心】产出 A：用通用模型反推字段级分级

> 这一节是本轮讨论的重点，记录最详细。它正好回到最初想做的东西——一个数据驱动的字段级分级——
> 但这次是从集合语义里**算出来**的。

### A.1　公式该长什么样

**不要直接写 `v(S) ≈ c + Σ wᵢ`。** 这个形式有三处会被打穿：

1. `v(∅) = 0` 是定义决定的（没有字段时 R² 就是 0），所以 **c 根本不该是自由参数**；
2. `v ≤ 1`，但 `Σ wᵢ` 无上界，集合一大必然溢出；
3. 数据**普遍饱和**（整池 0.99+），线性残差里混着饱和造成的曲率，不全是协同——
   **头条数字会被这一条直接质疑掉**。

三个毛病同一根源：**R² 不是一个可加的标度。**

#### 推荐的形式

在**对数残差标度**上做可加：

```
g(v) ≜ −½·ln(1 − v)          g(v(S)) ≈ Σ_{i∈S} wᵢ
```

等价的乘性写法更好懂——**残差方差相乘**：

```
1 − v(S) ≈ Π_{i∈S} ρᵢ ，   ρᵢ = e^{−2wᵢ} ∈ (0,1]
```

| 性质 | 怎么来的 | 含义 |
| --- | --- | --- |
| `c = 0` 自动成立 | 空积等于 1，即 `1 − v(∅) = 1` | **常数项不是拟合出来的，是被定义钉死的**。若放开拟合出非零值，那正是模型失配的诊断量 |
| 永不越界 | 若干 (0,1] 的数相乘仍在 (0,1] | `v < 1` 恒成立，饱和被吸收进标度本身 |
| 单调性自动满足 | 约束 `wᵢ ≥ 0`（非负最小二乘） | 与信息单调包络同源 |
| `wᵢ` 有单位 | 高斯情形下 `−½ln(1−R²)` 就是互信息 | **字段分数的单位是「奈特」** |

**理论解释**：对联合高斯的 `(X, Y)`，`I(X_S; Y) = −½ln(1 − R²_S)` 是标准结果。
于是**可加性成立，当且仅当各字段贡献的是互相独立的信息**。偏离可加性的两个方向正好是 PID 的两个词：

- **亚可加**（实际 < 模型）= **冗余**：字段之间信息重叠；
- **超可加**（实际 > 模型）= **协同**：合体产生了各自没有的信息。

> 这个公式不是凑出来的，它是"假设字段之间信息独立"的唯一自然写法，
> 而论文要讲的事——协同——恰好就是这个假设的违背量。**公式和论题是同一件事的两种说法。**
> 对三四区刊物，这个程度的理论支撑绰绰有余。

### A.2　「会互相矛盾」不是 bug，那正是要测的东西

用风电数字算一遍：

| 集合 | v | g(v) = −½ln(1−v) |
| --- | --- | --- |
| {风电出力} | 0.064 | 0.0331 |
| {风电占比} | 0.162 | 0.0884 |
| **可加模型的预测** | | **0.1215** |
| **{两者}的真实值** | 0.928 | **1.3155** |

**差 10.8 倍**，且这个裂口**无法通过调权重弥合**：把 w 抬高到能解释这一对，两个单字段预测就崩。
**没有任何一组 44 个数能同时满足这两类方程。**

> 这两行应该**放进引言**。两行就能验算、无法反驳，说明字段级分级不是"不够准"，
> 而是**被自身的形式所限制**。

由此得到必须写清楚的方法学立场：**因为 v 本来就不可加，所以 w 不是自然界的参数，而是一个投影。**
论文要做的不是找出"正确的 w"（不存在），而是
**(1) 说明投影到哪、(2) 报告投影之后不可调和的残差——残差就是结论。**

### A.3　投影到哪：权重的选择

| 加权方式 | 后果 | 判断 |
| --- | --- | --- |
| 在 `2ⁿ` 上均匀 | 质量全压在 `|S|≈22`，那里**全部饱和**，`g` 几乎不随集合变化 | **不可用**（退化） |
| 按基数分层均匀 | 可用，但"每层给多少权重"是无依据的自由选择 | 可作对照 |
| **Shapley 核** `π(S) ∝ 1/[|S|(n−|S|)]` | WLS 的解**恰好是 `g∘v` 的 Shapley 值**（KernelSHAP 经典结果） | **推荐**，有公理支撑 |

推荐 Shapley 核的三条理由（都不是"因为流行"）：

1. **效率性正好是监管想要的语义。** `Σᵢ wᵢ = g(v(全集)) − g(v(∅)) = g(v(全集))`——
   **所有字段的分数之和恰好等于"全量发布"的总信息泄露**，于是每个字段分数就是它在总风险里的**份额**。
   这是分级表最该有的性质，一句话能讲给非技术读者。
2. **非负性自动成立。** v 单调 ⟹ 单调博弈 ⟹ Shapley 值非负，不需额外约束。
3. **接到已有的线上。** SPVIM 做的正是"重训语义下预测能力的 Shapley 值"。
   区别很干净：**它抽 Θ(n) 个子集做统计推断，我们有能查任意集合的 oracle，
   因此可以做它做不了的事——把残差也测出来。**

> **必配的一个对照**：审稿人会说"也许只是你的权重选得不好"。所以要**同时报告最小二乘最优的那组 w**
> （不加任何公理约束，纯粹最小化预测误差）。如果 R² 只从 0.62 升到 0.65，
> **就证明差距是结构性的，与权重选择无关**。几乎不花钱，却挡掉最容易被提的质疑。

### A.4　选哪些集合、选多少

不用穷举，也不该随便随机。建议**预先登记的分层设计**：

| 层 | 取法 | 数量 | 作用 |
| --- | --- | --- | --- |
| 全部单点 | 穷举 | 44 | 直接锚定每个 `wᵢ` |
| 全部二元 | 穷举 | 946 | 锚定两两结构；也是协同主产地 |
| 3–8 阶 | 每阶均匀随机 | 6 × 2000 | **信息最丰富的区段**：既不平凡也未饱和 |
| 9 阶以上 | 稀疏抽 | ~2000 | 已接近饱和，信息量低 |
| 全集 | 必取 | 1 | 效率性的锚点 |

合计约 **2 万次查询**——direct 读出 **8 秒**，ridge2 读出 **6 分钟**。

> **不要偏向协同集合。** 拟合阶段多选协同会让可加模型把协同**吸进主效应**——
> w 被整体抬高，而"可加能解释多少"这个头条数字同时被污染，grading 和 gap 一起失真。
> **正确做法是把估计和评估分开**：中性分层设计上拟合；另建**评估集**，
> 里面专门留一个协同层，用来*报告*残差。**协同集合是用来量误差的，不是用来拟合的。**

**「选多少」的经验答案**：画**逐层信息曲线**（横轴基数 k，纵轴该层内 `g(v(S))` 的方差）。
方差塌缩处即饱和开始，那一层之后再采样也学不到东西。
这条曲线既是采样预算的依据，也就是论文里说明"饱和从哪一阶开始"的那张图。

### A.5　会不会有很多解？

**不会。** 2 万个方程、44 个未知数，严重超定的最小二乘，解唯一稳定
（设计矩阵的行是 0/1 指示向量，不同基数混合采样必然满秩）。

**真正的风险不是"多解"，而是"解随设计而变"**——因为 v 不可加，换采样测度就换投影。三个必做检查：

- **Bootstrap 置信区间**：对设计集重抽样，给每个 `wᵢ` 一个区间。
  区间宽到跨越两个分级档的字段，必须在分级表里标注"边界"。
- **跨设计的秩相关**：三种不同设计各拟合一次，报告两两 Kendall τ。
  **τ > 0.9 说明分级稳健；达不到就如实写出来**——这反而是诚实且有信息量的结果。
- **非负 + 岭正则**：既保证单调，也压住个别系数飞掉。

### A.6　为什么非要通用模型？

|  | 纯重训 | 用 oracle |
| --- | --- | --- |
| 单个机密字段一次拟合 | 2 万 × 30s ≈ **7 天** | 8 秒 ~ 6 分钟 |
| 12 个机密字段 × 3 个数据集 | ≈ **250 天** | 约 **1.5 小时**（含 36 次 oracle 训练） |

但**更有力的论点不是速度，是"买得起诊断"**：A.5 里那三项检查
**每一项都要把全流程再跑一遍**。查询便宜时它们是家常便饭；查询要 30 秒时只能跑一次，
**拿不出任何误差棒**。*一个没有置信区间的分级表，在监管场景里是不能用的。*

#### 必要性的最强论证：先把朴素分级证伪

做一个**朴素分级基线**：`wᵢ = g(v({i}))`，只要 **44 次查询**。
这就是"不用集合模型、直接拿单字段推断能力当分数"的做法，也是大多数人的第一直觉。

然后测它错得多离谱——它**既不含冗余也不含协同**：
在冗余重的字段组上系统性**高估**，在协同组上系统性**低估**。

> **这个基线只花 44 次查询，而它的失败就是"必须上集合级 oracle"的全部理由。**
> 一个 44 次查询能解决的问题，没人会去训一个通用模型；**先把它证伪，通用模型的位置才立得住。**

### A.7　怎么判断这个新分级是好的

前提必须写进论文：**不存在"真值分级"可供比对**，所以评估只能是**任务化**的。

| 标准 | 怎么测 | 回答什么 |
| --- | --- | --- |
| **① 决策一致性**（主判据） | 留出集合上比较规则 `Σ_{i∈S} wᵢ ≤ θ` 与真值 `v(S) ≤ τ`；**在相同保守误判水平下比危险误判**（直接复用已有的保守程度对照协议） | 当成发布规则用，安全吗？**唯一直接对应用途的指标** |
| **② 扣留曲线** | 按分级从高到低**扣留**前 k 个字段，重训测剩余的 v，画 k–v 曲线；对比随机序 / 单字段 R² 序 / IGNN 序 / 本文序 | 排序对不对。**用"扣留最危险的"而非"发布最安全的"**，因为前者才是安全语义；方法论对应 ROAR |
| **③ 监管形态检验**（最实用） | 把 w 离散成 3–5 级（对齐现行分类分级规范），执行"发布 ≤ ℓ 级的全部字段"，测每个 ℓ 的真实 v | **它实际会被使用的形式下，安全吗？** 同时精确暴露落在同一允许等级里的协同对——**这张表本身就是论题的证据** |
| **④ 稳定性** | Bootstrap CI；**跨年秩相关**（`pjm_2024` vs `pjm_2025`） | 能不能当监管依据。**年年翻转的分级表没法执行**，跨年 Kendall τ 高是极强的有效性证据 |

再加一条**负对照**：把目标列打乱后重拟合一份分级，在 ①②③ 上都应不优于随机。
几乎不花钱，却挡掉"你的指标是不是自己定义出来的"。

### A.8　通用模型自身的对比实验

现有阶梯数据：共享读出 0.606/0.130 → 仿射 0.676/0.199 → poly2 0.680/0.760 → last 0.732/0.781 →
L1 元训练 0.808/0.858；50 步查询微调 ρ=0.899 而 L0 零训练 ρ=0.904；成本 55.5ms vs 2.5ms，**22.4×**。

**但在这篇论文里，把对比的落点从"估计器保真度"换成"分级结果"**：
每个估计器各产出一份分级，然后报告

- 两份分级之间的 **Kendall τ**；
- **有几个字段挪动了 ≥2 个等级**；
- 各自在 A.7 的 ①②③ 上表现差多少。

> 「用共享读出会让 5 个字段的密级评错」**比「MAE 从 0.11 降到 0.04」有说服力得多**，
> 因为它把估计误差翻译成了读者关心的后果。
> 微调那条同理：报告**要微调多少步才能追平零训练闭式读出的分级**，以及多花多少时间。

## 10. 论文方案

### 题目候选

- **推荐**：Sets, Not Fields: Certifiable Set-Level Sensitivity Assessment for Data Inference Leakage in Power Grid Data Sharing
- 稳健版：Certifiable Set-Level Sensitivity Auditing against Data Inference Leakage in Cyber-Physical Power Grids
- 中文版：集合而非字段：面向电网数据推断泄露的可认证集合级敏感度评估

### 论题（否定性的，有赌注）

> 现行数据分级——包括 IGNN 这类自动化方法、也包括各类分类分级规范——把密级授予**字段**。
> 但推断泄露是**集合**的属性。因此**字段级分级在原理上无法表达推断风险，无论分数打得多准**。
>
> 要正确分级必须评估集合；要评估集合必须面对 2⁴⁴ 次重训；要负担得起必须摊销；
> 而摊销恰好在最危险的集合上失明。**这就是全部的情节。**

好在四点：否定性的（有冲突）；一行实验就能证明（风电那组数）；
把离开 IGNN 从"退却"变成"贡献"；直接关涉政策（现行电力数据分级规范全是字段级的）。

### 三幕结构

1. **第一幕 · 否定**：分级的单位错了。从 IGNN 接上，风电数字开场，格图落锤，
   两条排除性对照（图上扩散 / 共享读出）。读者接受"必须评估集合"，代价立刻摆上桌。
2. **第二幕 · 转折**：摊销在最该准的地方最不准。负面诊断 + 机制归因 + 修法四件套 + 认识论红线
   + 字典证伪（441 个五阶强协同无一为真）。
3. **第三幕 · 回报**：字段级分级的最优形式及其可证误差（第 9 节）、
   安全发布边界、被认证的衰减律、估计器自己的可用边界 k\*=5。收尾回到第一幕。

### 开场段（六句，不超过一段）

(1) 电网数据共享前只删机密字段，物理耦合仍在 → (2) 现行做法给*字段*定密级，包括最新自动化方法 →
(3) 一行反例：风电出力 0.064、风电占比 0.162、合体 0.928 → (4) **密级是集合的属性** →
(5) 代价：2⁴⁴ 个集合 → (6) 本文做什么。

### 贡献五条（第一条必须是否定性的）

1. **论题，并且是量化的。** 字段级分级的表达力上界；
   在对数残差标度上拟合最优可加模型并报告残差——把论题从断言变成一个数字；
   配套阶梯（可加 → 两两 → 三阶）给出"分级表要复杂到什么程度才够用"的可执行答案。
2. **策略形式。** 可发布域下闭、由极大元刻画；字段级只能表达子立方体。
3. **诊断。** 尾部失明 + 三个排除性对照 + 值函数摊销间隙的机制归因。
4. **算法。** 三条多项式次查询的搜索（贪心+二分认证 / 从全集缩 / 束搜索），
   零查询剪枝 `syn(S) ≤ 1 − max_{T⊊S} v(T)`，通道清单建好后下游退化为纯组合问题。
5. **验证、定标与工作包络。** 多电网复现；字典方法的认证级证伪；被认证的衰减律；
   k\*=5 及其三段式成因；方法对估计质量的依赖刻画（安全性无关、效用强相关）。

### 措辞纪律（从 97 号继承，务必保留）

- 「最危险的协同是低阶的」必须限定为「**在可认证范围内（k≤5）**」。
  外推七阶最强协同约 0.25(PJM)/0.15(CAISO)，仍在 0.10 显著阈之上——
  正确表述是「**存在但不可认证**」，不是「不存在」。安全语境下这两句含义相反。
- 注入定标给出的是**能力上界**，不得读作真实性能预期。
