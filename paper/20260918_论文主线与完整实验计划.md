# 1. 一句话概括论文

本文研究的不是“某个固定模型依赖哪些字段”，而是：

**当电力数据发布者需要任意查询、低阶穷举或快速发现潜在危险字段组合时，如何高效估计任意公开字段集合 S 对敏感目标 Y 的样本外推断能力，并进一步把集合级推断能力转化为具有攻击者背景知识语义的字段级推断风险。**

整篇论文由两个前后衔接的核心部分组成：

1. **Subset-level inferability estimation**：给定敏感目标 Y，对任意字段集合 S，快速估计其推断能力 \(V_y(S)\)；
2. **Field-level inference-risk quantification**：基于 \(V_y(S)\)，定义背景预算约束下的最大边际推断能力 \(M_{i\to y}^{(K)}\)，得到字段风险强度以及对应的危险背景 witness。

最终链路：

\[
	ext{任意字段集合 }S
ightarrow
\hat V_y(S)
ightarrow
\hat M_{iightarrow y}^{(K)}
ightarrow
	ext{字段风险分级 + witness 背景}
\]

# 2. 论文真正要回答的两个问题

## Q1：任意字段集合 S 对敏感目标 Y 到底能推断到什么程度？

这里的“任意字段集合”不是为了强调理论上的 \(2^p\) 全枚举，而是对应真实安全审计中三类需求。

### 场景 A：任意查询

数据发布者临时给出一个待发布字段集合 \(S\)，希望立即知道：

\[
V_y(S)
\]

即这些字段对目标 \(Y\) 的样本外推断能力。

传统方式需要针对 \(S\) 单独重新训练一个攻击模型。若审计请求很多，重复训练开销很大。

### 场景 B：低阶穷举

为了研究单字段、二字段、三字段等低阶组合风险，需要大量查询：

\[
V_y(S),\quad |S|\le r
\]

例如计算 \(K=2\) 的 \(M\) 时，需要反复评估大量规模不超过 3 的字段集合。

### 场景 C：快速发现危险背景

在更大的候选空间中，希望快速寻找能够显著提升推断能力的背景组合，而不是先对所有组合逐个完整重训。

因此，Q1 的核心不是“能不能训练一个预测模型”，而是：

**能否通过一次目标特定的预学习，在后续大量不同字段子集任务上快速获得可靠的 out-of-sample inferability。**

---

## Q2：集合级 \(V_y(S)\) 如何转化成字段级安全量？

仅有 \(V_y(S)\) 仍然不能直接用于字段分类分级。

我们真正关心的是：

> 当攻击者已经掌握一定背景信息时，再公开字段 \(i\)，最多能够使敏感目标 \(Y\) 的推断能力增加多少？

因此定义 \(M_{i\to y}^{(K)}\)，把集合级推断能力转化为字段级最大边际推断风险。

Q1 解决“任意组合的推断能力怎么快速算”。

Q2 解决“算出来以后，怎样形成字段级风险指标并服务于分级和发布审查”。

这两个问题必须始终保持前后关系，不写成两个互不相关的方法。

# 3. 最终方法口径：单目标预学习、字段子集通用

正式论文建议不再以“一个 backbone 同时预测 12 个 Y”为主版本。

对每一个敏感目标 \(Y_y\)，单独预学习一个目标特定的通用特征提取器：

\[
\phi_{	heta_y}(X,m)
\]

其中：

- \(y\)：当前敏感目标；
- \(m\)：字段可见掩码；
- \(S\)：由 \(m\) 对应的可见字段集合。

因此“通用”的含义固定为：

**对字段子集 \(S\) 通用，而不是对不同目标 \(Y\) 通用。**

这样可以让模型定义、\(V_y(S)\)、\(M_{i\to y}^{(K)}\) 从头到尾保持同一个目标语义。

多目标模型只作为一次消融实验，与 single-target 版本比较；如果单目标版本不劣，则正文完全采用单目标版本。

# 4. Threat Model 与数据使用边界

## 4.1 角色

### Auditor

数据拥有者 / 数据发布者。

其持有完整历史数据，包括敏感目标 \(Y\)，用于离线安全审计。

### Adversary

假设攻击者具有一定历史辅助标签数据，可基于公开字段训练推断器；最终风险由独立测试数据上的 out-of-sample 推断能力刻画。

因此本文衡量的是：

**supervised inferability / attack potential**

而不是 zero-shot inference。

---

## 4.2 训练标签不构成测试泄露

对给定字段集合 \(S\)，闭式输出层只允许使用训练集真实值：

\[
Y_y^{train}
\]

求得：

\[
eta_{y,S}
\]

测试阶段固定该参数：

\[
\hat Y_y^{test}=Z_{y,S}^{test}eta_{y,S}
\]

测试真实值：

\[
Y_y^{test}
\]

只能用于最终计算：

\[
R^2
\]

不能参与：

- backbone 训练；
- \(eta\) 求解；
- \(\lambda\) 选择；
- checkpoint 选择；
- witness 搜索中的模型拟合。

论文必须明确写出这一区分，避免“使用 Y 是否作弊”的歧义。

# 5. 集合级推断能力的三层对象

## 5.1 理想总体能力

\[
V_y^*(S)
=
1-
rac{\inf_f \mathbb E[(Y_y-f(X_S))^2]}
{\mathrm{Var}(Y_y)}
\]

表示只使用字段集合 \(S\) 时理论上能够达到的最佳总体推断能力。

\(V_y^*(S)\) 天然单调，因为攻击者获得更多字段后可以选择忽略新增字段。

---

## 5.2 专用重训经验能力

\[
V_{y,retrain}(S)
\]

对每个 \(S\) 单独训练指定攻击器族中的模型，在 validation 上选择模型/轮次，在独立 test 上报告 \(R^2\)。

它作为本文低阶组合实验的经验真值。

建议最终攻击器族至少包含：

- DNN；
- HistGradientBoosting / XGBoost / LightGBM 中至少一种树模型。

经验攻击能力建议定义为：

\[
V_{y,retrain}(S)
=
\max_{h\in\mathcal H} R^2_{test}(h_S)
\]

其中攻击器选择只能基于 validation。

---

## 5.3 通用模型估计能力

\[
\hat V_y(S)
\]

由目标特定的通用推断模型快速得到。

论文的第一大方法任务就是证明：

\[
\hat V_y(S)pprox V_{y,retrain}(S)
\]

并且更重要地：

\[
\hat \Delta_{i,y}(T)
=
\hat V_y(T+i)-\hat V_y(T)
\]

能够保持真实边际结构。

# 6. 第一大方法：Target-Specific Subset-Universal Inference Model

建议论文中不用 L0 / L1 作为正式方法名。内部实验编号仍可保留。

正文主版本建议命名为：

**Target-Specific Subset-Universal Inference Model**

或简写为：

**Subset-Universal Inference Model**

核心由“随机掩码预学习 + 共享目标特定表征 + 集合特定闭式读出”组成。

---

## 6.1 阶段一：Random-Mask Pre-learning

固定一个敏感目标 \(Y_y\)。

对于训练样本 \(x\)，随机生成：

\[
m\in\{0,1\}^p
\]

输入：

\[
z=[x\odot m,m]
\]

显式输入 \(m\) 的原因是：标准化后的数值 0 可能是真实取值，也可能代表字段被遮蔽。

预学习模型：

\[
f_{	heta_y}(x,m)ightarrow Y_y
\]

训练阶段持续随机改变可见字段集合，使模型学习：

**在不同信息条件下，对同一目标 \(Y_y\) 有用的共享条件表征。**

最终不直接保留共享输出头，而是保留：

\[
\phi_{	heta_y}(x,m)
\]

作为目标特定通用特征提取器。

---

## 6.2 阶段二：对任意字段集合 S 的快速适配

给定一个以前未专门训练过的字段集合 \(S\)，固定对应 mask：

\[
m_S
\]

通过冻结的 feature extractor 得到：

\[
\Phi_{y,S}
=
\phi_{	heta_y}(X,m_S)
\]

当前建议保留已经验证有效的旁路特征：

\[
Z_{y,S}
=
[
\Phi_{y,S},
X_S,
X_S^2
]
\]

然后仅针对当前字段集合 \(S\) 和目标 \(y\) 求闭式 Ridge 读出：

\[
eta_{y,S}
=
(Z_{y,S}^{T}Z_{y,S}+\lambda I)^{-1}
Z_{y,S}^{T}Y_y^{train}
\]

其中 \(\lambda\) 只能在训练数据内部 validation 上选择。

最终测试：

\[
\hat Y_y^{test}
=
Z_{y,S}^{test}eta_{y,S}
\]

并得到：

\[
\hat V_y(S)
=
R^2(Y_y^{test},\hat Y_y^{test})
\]

核心思想可以概括为：

**昂贵的 representation learning 在所有 \(S\) 之间共享；廉价的 readout adaptation 针对每个 \(S\) 单独快速完成。**

---

## 6.3 为什么不直接使用共享输出头

Direct Oracle：

\[
[X\odot m,m]
ightarrow
	ext{shared backbone}
ightarrow
	ext{shared output head}
ightarrow
Y
\]

所有字段集合被迫共享同一个输出读出结构，容易产生 amortization gap。

本文主版本改成：

\[
[X\odot m,m]
ightarrow
\phi_{	heta_y}
ightarrow
eta_{y,S}
ightarrow
Y_y
\]

即：

- backbone 跨 \(S\) 共享；
- readout 对 \(S\) 特定。

论文实验必须通过 Direct Oracle vs subset-specific readout 的消融证明这一结构的必要性。

---

## 6.4 L1 / meta-learned feature 的定位

可微闭式 Ridge、support/query 元训练不是本文核心原创机制。

因此建议：

- 正文主方法优先采用最简单、最稳定的 frozen-feature + closed-form readout；
- L1 / meta-learned feature 作为强消融或增强版本；
- 如果 single-target L1 在两个数据集上都显著降低 M-MAE，并且没有明显增加复杂性，则可升级为正文增强模型；
- 否则保留在附录，不破坏主线。

# 7. 第二大方法：背景预算约束最大边际推断能力 \(M^{(K)}\)

对目标 \(Y_y\)、字段 \(i\)、公开基底 \(B\)、攻击者背景预算 \(K\)，定义：

\[
M_{iightarrow y}^{(K)}
=
\max_{\substack{T\subseteq H\setminus\{i\}\|T|\le K}}
\left[
V_y(B\cup T\cup\{i\})
-
V_y(B\cup T)
ight]
\]

解释：

> 攻击者已经拥有公开基底 \(B\)，并且最多还能掌握 \(K\) 个其他候选字段时，再公开字段 \(i\)，最多能够带来多少额外推断能力。

\(K\) 不是普通超参数，而是攻击者背景知识预算。

---

## 7.1 必须保留 witness background

在计算 \(M\) 时同时保存：

\[
T_{i,y}^{*}
=
rg\max_{|T|\le K}
[
V_y(B\cup T+i)-V_y(B\cup T)
]
\]

最终一条结果应至少包含：

- 字段 \(i\)；
- 敏感目标 \(y\)；
- \(M_{i	o y}^{(K)}\)；
- witness \(T^*\)；
- witness 下的基础 \(V\)；
- 加入字段后的 \(V\)；
- 是否跨越指定安全阈值。

witness 的意义：

**告诉数据管理者“为什么这个字段危险、在什么已有信息条件下危险”。**

注意：

- witness 不宣称唯一；
- 多个近等效背景可以同时存在；
- 内部建议保留 top-3 witness 及其边际值；
- 正文表格只展示最强或最有代表性的一个；
- 不再额外定义“背景多样性指标”，避免论文碎片化。

---

# 8. \(M^{(K)}\) 与已有 MCI 的关系

定义条件评价函数：

\[
v_B(T)=V(B\cup T)-V(B)
\]

则 \(M^{(K)}\) 是该条件函数上限制背景大小不超过 \(K\) 的 budget-constrained MCI。

当：

\[
K\ge |H|-1
\]

时：

\[
M_i^{(K)}=MCI_i
\]

论文必须主动承认：

以下内容不是本文原创：

- 最大边际思想；
- 单字段下界；
- duplication invariance；
- MCI super-efficiency；
- context / witness；
- Shapley 在重复/替代字段下被稀释。

本文真正新增和保留的理论重点是：

1. 公开基底 \(B\) 与攻击预算 \(K\) 的安全威胁模型参数化；
2. 截断背景下的性质；
3. 带基底 \(K=1\) 的闭式关系；
4. 与阈值安全 / 小规模发布预算相关的结果；
5. 通用估计误差向 \(M\) 误差的传播。

# 9. 正文理论只保留必要内容

正文建议只保留以下几个定义 / 命题。

## Definition 1：\(V_y(S)\)

字段集合 \(S\) 对特定敏感目标 \(Y_y\) 的推断能力。

## Definition 2：\(M_{i	o y}^{(K)}\)

字段在有限攻击者背景下的最大增量推断能力。

## Property 1：K 单调

\[
M_i^{(0)}
\le
M_i^{(1)}
\le
\cdots
\]

用于解释 inference escalation profile。

## Property 2：K=1 的协同关系

带公开基底 \(B\) 定义：

\[
a_i^B=V(B+i)-V(B)
\]

\[
I_{ij}^B
=
V(B+i+j)-V(B+i)-V(B+j)+V(B)
\]

则：

\[
M_i^{(1)}
=
a_i^B+
\max(0,\max_j I_{ij}^B)
\]

说明 \(M^{(1)}\) 在单字段能力基础上增加的是最大正二阶协同。

## Property 3：通用估计器误差传播

设：

\[
\Delta_i(T)=V(T+i)-V(T)
\]

\[
\hat\Delta_i(T)=\hat V(T+i)-\hat V(T)
\]

则：

\[
|\hat M_i-M_i|
\le
\max_T
|\hat\Delta_i(T)-\Delta_i(T)|
\]

这条命题直接连接“通用模型的边际保真度”与最终 \(M\) 的准确性。

## Property 4：安全相关定理

正文最多再保留一个：

\[
V(B\cup A)-V(B)
\le
\sum_{i\in A}M_i^{(K)},
\qquad |A|\le K+1
\]

作为小规模发布集合的保守推断风险预算。

其余理论全部放附录。

# 10. 多个敏感目标如何处理

论文的基本分析单位是：

\[
(i,y)
\]

因此一个字段可能对不同目标拥有不同风险。

主结果保留目标特定矩阵：

\[
M_{iightarrow y}^{(K)}
\]

如果最终业务必须给每个字段一个总体等级，建议采用：

\[
Score_i^{(K)}
=
\max_{y\in\mathcal Y_{sens}}
M_{iightarrow y}^{(K)}
\]

并同时保存：

\[
y_i^*
=
rg\max_y M_{iightarrow y}^{(K)}
\]

以及对应 witness：

\[
T_i^*
\]

安全场景优先使用 max，而不是对目标求平均，避免某个高风险目标被其他低风险目标稀释。

# 14. Part A：通用模型实验
