## 1. 主线定位

**问题**：电力公开数据中，字段之间存在关联和组合推断能力。单字段相关性、单字段预测准确率，以及固定全量模型上的 SHAP/SAGE，都不能完整反映"攻击者掌握其他背景信息时，一个字段可能造成的额外推断增益"。

**两个组成部分**：
1. **随机掩码通用推断模型**：解决"任意字段集合 S 对目标 Y 的推断能力 V(S) 如何低成本获得"；
2. **M_i^(K)**：解决"如何把集合级推断能力转化为适合数据安全分级的字段级量"。

**不作为并列主线的内容**：Shapley/SAGE/SPVIM 只作相关工作和对照实验；interaction 只用于解释 M^(1) 为什么升高；路径搜索与最小路径枚举不纳入。

**与现有代码、实验是否一致**（逐项核对）：

| 主线要素 | 现状 | 是否一致 / 调整 |
| --- | --- | --- |
| V(S) 由随机掩码通用模型给出 | 75 号 uniform 掩码 MLP + 91 号闭式读出（L0），98 号三种子特征集成 + x,x²（L0ensx） | 一致。**正文主估计器固定为 L0ensx**，L0 / 共享头 / L1 作消融 |
| V(S) 的"真值" | 60–69 号逐集合重训；98 号起并行专用重训（val 选轮次） | 一致；100 号起**攻击器族 = DNN + 梯度提升树**，按 val 选择 |
| M^(K) 带基底 B | 98/99 号只做了 B=∅ | **不一致 → 100 号补 PJM 公开负荷预测基底场景** |
| 完整字段集 | 98/99 号只有 p=12/14 的博弈 | **不一致 → 100 号在去别名的 41 字段上精确计算 M^(0..3)** |

## 2. 三层对象

**V\*(S)（总体最优推断能力）**
V\*(S) = 1 − inf_{f 可测} E[(Y−f(X_S))²]/Var(Y) = Var(E[Y|X_S])/Var(Y)。
它天然满足 V\*(∅)=0、0≤V\*≤1、S⊆T ⇒ V\*(S)≤V\*(T)，因为多给的字段可以忽略。

**V_retrain(S)（经验攻击能力）**
给定有限数据 D=(fit, val, test) 与攻击器族 𝓗（本文为 DNN 与梯度提升树），对每个 S 逐个专用训练 h∈𝓗，在 val 上选轮次与攻击器，在 test 上报告 R²：
  V_retrain(S) = R²_test(ĥ_S)，ĥ_S = argmax_{h∈𝓗, 训练轮次} R²_val(h; S)。
由于有限样本、优化误差和选择噪声，**V_retrain 不必单调**（99 号核验：7–9% 的集合相差 0.01 以上，最大 0.09）。

**V_amortized(S)（通用模型估计）**
一次训练的随机掩码模型在 S 下查询得到的 R²（冻结主干 + 逐集合闭式读出，读出只用 train）。

**单调闭包（本文使用的风险对象）**
攻击者拿到 S 后，可以只在任意子集 T⊆S 上训练攻击器并挑选最好的一个。所以经验攻击能力的合理定义是
  **V̄(S) = V(T̂_S)，T̂_S = argmax_{T⊆S} V_val(T)**（在 val 上挑子集，test 上报告）。
当选择与报告用同一份数据时，它退化为 max_{T⊆S} V(T)。

- **解释**：V̄ 是**对经验攻击能力的单调闭包**（monotone closure of empirical attack capability），**不是**把"单调包络"当作物理风险的定义。总体层面 V\* 本来就单调，闭包只是修复有限样本造成的非单调。
- 闭包对 V_retrain 与 V_amortized 同样适用。
- 计算 M^(K) 只需要规模 ≤K+1 的集合，而这些集合的子集规模更小，所以**闭包不破坏 M^(K) 的局部性**。

下文 V 统一指某一层的单调闭包 V̄；需要区分层时写 V\*、V_retrain、V_amortized。

## 3. 定义与 MCI 的关系

### 3.1 正文只保留四个定义

- **定义 1（集合推断能力）** V(S)：见 §2，默认取经验攻击能力的单调闭包。
- **定义 2（背景受限最大边际推断能力）**：给定目标 c、公开基底 B、候选字段 H=G∖B、背景预算 K，
  **M_i^(K) = max_{T⊆H∖{i}, |T|≤K} [ V(B∪T∪{i}) − V(B∪T) ]**，
  取到最大值的 T\* 称为**见证背景**（witness；Catav 称 context）。
- **定义 3（单字段能力）** a_i^B = M_i^(0) = V(B∪{i}) − V(B)；B=∅ 时为 V({i})。
- **定义 4（二阶交互，仅用于解释）** I_ij^B = V(B∪{i,j}) − V(B∪{i}) − V(B∪{j}) + V(B)。

### 3.2 Catav 等（ICML 2021）原文核查

逐页核对 PMLR 版原文，结论如下。

- **定义**：给定单调非减、ν(∅)=0 的评价函数 ν:𝒫(F)→ℝ⁺，MCI 定义为
  I_ν(f) = max_{S⊆F} Δ(f,S,ν) = max_{S⊆F} [ν(S∪{f}) − ν(S)]，
  S 可以为空；f∈S 时 Δ=0，不影响最大值，所以等价于只在 f∉S 上取最大值。
- **ν 的来源**：采用 Covert 等（2020）的 universal predictive power，ν(S) = min_ŷ E ℓ(ŷ,Y) − min_{g∈G(S)} E ℓ(g(X),Y)；并指出 G(S₁)⊆G(S₂) 时 ν 单调。实验中 ν 由逐子集重训模型的交叉验证或测试性能给出（Elastic-Net 的 VAR(Y)−MSE、MLP 准确率、逻辑回归 log-loss、LightGBM AUC）。
- **公理**（Definition 2）：
  (1) marginal contribution：I(f) ≥ ν(F) − ν(F∖f)；
  (2) elimination：删去字段集合后，其余字段的重要性不增；
  (3) minimalism：满足 (1)(2) 的最小函数。
- **Theorem 1**：ν 单调时，MCI 是唯一满足三公理的函数。
- **Theorem 2**：dummy；symmetry；**super-efficiency** ∀S: ν(S) ≤ Σ_{f∈S} I(f)；sub-additivity；**upper bound the self contribution** I(f) ≥ ν({f})；**duplication invariance**（删去一个副本不改变其他字段的 MCI）。
- **context**：满足 I(f)=Δ(f,S,ν) 的 S 称为 context，可以给出额外解释。
- **计算**：精确计算是指数级；ν 次模时存在多项式算法（补充材料 C.I）；任何基于采样的方法都给出**下界**；补充材料 C.II 给出分支定界用的**上界**。实验中用 2^14–2^15 个随机排列的前驱集合估计。
- **Theorem 3**：有限样本下，ν 的经验估计一致收敛，MCI 误差受控（有限假设类、0-1 损失）。
- **动机例子**：Shapley 在相关、重复特征下低估；Y=f1∧(f2∨f3) 中把 f1 复制 3 次，f1 的 Shapley 从 0.65 降到 0.15。
- **没有**：背景规模限制、公开基底、阈值/安全语义、最小不安全集合、摊销估计器。

### 3.3 M^(K) 与 MCI 的严格关系

**命题 3.1**。令 v_B(T) := V(B∪T) − V(B)，T⊆H。
(a) v_B 单调、v_B(∅)=0、v_B≥0，满足 Catav 对评价函数的全部假设；
(b) M_i^(K) = max_{T⊆H∖i, |T|≤K} [v_B(T∪i) − v_B(T)]，即 **M^(K) 是条件评价函数 v_B 上的背景预算约束 MCI**（budget-constrained / truncated MCI）；
(c) 当 K ≥ |H|−1 时，M_i^(K) = MCI_{v_B}(i)；B=∅ 时即为 V 上的原始 MCI。

*证明*。(a) V 单调且 B∪T ⊆ B∪T′；v_B(∅)=V(B)−V(B)=0。(b) V(B∪T∪i) − V(B∪T) = v_B(T∪i) − v_B(T)。(c) 预算约束失效，max 的可行域变为全部 T⊆H∖i。∎

**注**。条件评价函数 v_B 也可以写成"在攻击者已知 B 条件下的剩余推断能力"。它与"归一化条件能力" r(T|B)=v_B(T)/(1−V(B)) 相差一个与 i、T 无关的正因子，所以两种写法的见证背景相同、M 相差同一因子。正文用 v_B，因为它与绝对风险阈值同一口径。

## 4. 定理与证明

以下 V 指某一层的单调闭包（单调、V(∅)=0）。凡用到单调性的地方都会标出。

### 定理 1（截断 super-efficiency 与逐阶预算）

对任意 A⊆H：
(a) 若 |A| ≤ K+1，则 **V(B∪A) − V(B) ≤ Σ_{i∈A} M_i^(K)**；
(b) 令 U^(K)(∅)=0，U^(K)(A) = min_{j∈A} [U^(K)(A∖j) + M_j^(min(|A|−1,K))]。若 |A| ≤ K+1，则 V(B∪A)−V(B) ≤ U^(K)(A) ≤ Σ_{i∈A} M_i^(K)；
(c) 若对所有 i∈A 有 M_i^(K) = M_i^(|A|−1)，则 (a)(b) 对该 A 成立，不需要 |A|≤K+1。

*证明*。(a) 任取顺序 i_1..i_m（m=|A|）做链式展开：v_B(A) = Σ_t [v_B(A_{t}) − v_B(A_{t−1})]，A_t={i_1..i_t}。第 t 项是 i_t 在规模 t−1≤K 的背景上的边际，所以 ≤ M_{i_t}^(K)。这一步只用到 v_B(∅)=0。
(b) 对 |A| 归纳：v_B(A) = v_B(A∖j) + Δ_j(B∪A∖j) ≤ U(A∖j) + M_j^(|A|−1)，对 j 取最小。第二个不等式来自 M^(k) 对 k 单调。
(c) 把 (a) 中每一步的上界换成 M^(|A|−1)=M^(K)。∎

- **与 MCI 的关系**：K ≥ |H|−1 时 (a) 就是 Catav 的 super-efficiency（条件评价函数 v_B 上）。因为 M^(K) ≤ MCI，**(a) 是比 super-efficiency 更强的截断不等式，不是它的推论**，所以需要单独证明；证明技巧（链式展开）与 super-efficiency 相同。(b)(c) 是新的。
- **核验**：随机带基底 4 人博弈（3000 个）零违例；99 号精确博弈零违例。

### 定理 2（通用安全余量）

定义三种余量：
- **统一边际界**：m 满足 Δ_i(B∪T) ≤ m 对所有 |T|≤K 成立；
- **通用余量**：m 满足"对所有 τ∈ℝ、所有 |T|≤K：V(B∪T) ≤ τ−m ⇒ V(B∪T∪i) ≤ τ"；
- **固定 τ 余量**：对给定 τ，m_τ = inf{ m ≥ 0 : ∀|T|≤K, V(B∪T) ≤ τ−m ⇒ V(B∪T∪i) ≤ τ }。

**(a)** m 是统一边际界 ⇔ m 是通用余量 ⇔ m ≥ M_i^(K)。所以 M_i^(K) 是**最小的通用余量**。
**(b)** 对任意 τ，m_τ ≤ M_i^(K)，并且不等号可以严格成立。

*证明*。
(a) 统一边际界 ⇔ m ≥ max Δ = M，由定义。
通用余量 ⇒ 统一边际界：对任一 T 取 τ=V(B∪T)+m，得 Δ_i(B∪T) ≤ m。
统一边际界 ⇒ 通用余量：V(B∪T∪i) = V(B∪T)+Δ ≤ τ−m+m = τ。
(b) M 满足固定 τ 的条件，所以 m_τ ≤ M。严格性由例子给出：B=∅，V(i)=0.1、V(j)=0.5、V(ij)=0.9，K=1，则 M_i^(1)=0.4；τ=0.95 时 T∈{∅,{j}} 加 i 后都不超过 0.95，m_τ=0；τ=0.7 时 m_τ=0.2。∎

**含义**：M 是**与阈值无关**的字段属性，适合写进分级表。对具体阈值的发布审查，m_τ 可能更小，所以 M 在固定阈值下是保守的。**正文不写"M 是给定 τ 下的最小余量"。**

### 定理 3（关键性 ⇔ 小最小不安全集合；需要单调）

在基底 B 下，称 E⊆H 为 τ-最小不安全集合（MUS），如果 V(B∪E)>τ 且对所有 E′⊊E 有 V(B∪E′)≤τ。称 i 为 K-背景 τ-关键字段，如果存在 |T|≤K、i∉T 使 V(B∪T) ≤ τ < V(B∪T∪i)。若 **V 单调** 且 V(B)≤τ，则

  **i 是 K-背景 τ-关键 ⇔ i 属于某个规模 ≤K+1 的 MUS。**

*证明*。
(⇐) E∋i 是 MUS，|E|≤K+1。取 T=E∖i，则 V(B∪T)≤τ（最小性），V(B∪E)>τ。
(⇒) V(B∪T)≤τ<V(B∪T∪i)。在 T∪i 的不安全子集中取包含关系下的极小元 E，它是 MUS 且 |E|≤K+1。若 i∉E，则 E⊆T，由**单调性** V(B∪T) ≥ V(B∪E) > τ，矛盾。∎

- **单调性是必要的**：非单调反例 V(1)=0.8、V(13)=0.2、V(3)=0.2、V(123)=0.9、τ=0.5。字段 2 在背景 {1,3} 上越过阈值，但任何含字段 2 的不安全集合都包含不安全真子集 {1}，所以不是 MUS。
- **核验**：随机单调 4 人博弈零违例；99 号精确博弈在 V_retrain 上 0.2% 不一致，在闭包上 0。
- **与 M 的联系**（由定理 2）：若 M_i^(K) ≤ m，i 只可能在 V(B∪T) ∈ (τ−m, τ] 的背景上成为关键字段。

### 命题 4（带基底 K=1 闭式；交互只作解释）

  **M_i^(0) = a_i^B，　M_i^(1) = a_i^B + max(0, max_{j∈H∖i} I_ij^B).**

*证明*。M^(0)：唯一背景 T=∅。M^(1)：背景为 ∅ 或 {j}，而 Δ_i(B∪{j}) = V(B∪ij) − V(B∪j) = a_i^B + I_ij^B。∎（不需要单调；B=∅ 时 V(∅)=0 自动成立。随机带基底博弈零违例。）

**解读**：M^(1) − M^(0) = max_j (I_ij^B)_+，**字段因联合推断升档，当且仅当它与某个伙伴严格超可加**。
项目早期的 syn₂(ij)=V(ij)−max(a_i,a_j) 满足 I_ij = syn₂ − min(a_i,a_j)，所以 **syn₂>0 不等于升档**。例：a_i=0.9、a_j=0.1、V(ij)=0.95 时 syn₂=0.05，I=−0.05，双方都不升档。

### 命题 5（层级、全集单调、复制不变：MCI 性质的截断版）

(a) M_i^(0) ≤ M_i^(1) ≤ … ≤ M_i^(|H|−1)；
(b) 候选字段集由 H 扩大到 H′⊇H 时，M_i^(K)(H′) ≥ M_i^(K)(H)（截断 elimination）；
(c) 若 f′ 是 f 的副本（对所有 T 有 V(B∪T∪f′)=V(B∪T∪f)=V(B∪T∪{f,f′})），删去 f′ 不改变其他字段的 M^(K)（截断 duplication invariance）。

*证明*。(a)(b) 都是更大可行域上的最大值。
(c) 对 i≠f,f′：若见证 T 含 f′：当 f∉T 时用 T′=(T∖f′)∪f，规模不变、值不变；当 f∈T 时用 T′=T∖f′，规模更小、值不变。T′ 仍在预算内，所以删除副本后最大值不降，由 (b) 也不升。∎

**Γ_i^(K) := M_i^(K) − M_i^(0) = 0 ⇔ ∀|T|≤K：Δ_i(B∪T) ≤ Δ_i(B)**（相对空背景无放大）。
- 这**严格弱于**次模性（次模要求所有 S⊆T 边际递减）。
- 反例（3 人单调博弈，B=∅）：V(1)=0.8、V(2)=0.6、V(3)=0.8，V(12)=V(13)=V(23)=0.8，V(123)=1.0。三个字段都有 M^(2)=a，但 Δ_1({3})=0 < Δ_1({2,3})=0.2，不是次模。
- 所以**只能说"次模 ⇒ 无升档"，不能说"升档 ⇔ 协同"**。

### 命题 6（不可约协同的字段级下界）

定义 S 的**不可约增益**（强度）syn^B(S) = V(B∪S) − max_{T⊊S} V(B∪T)，则对 |S|≥2：

  **syn^B(S) ≤ min_{j∈S} M_j^(|S|−1).**

*证明*：max_{T⊊S} V(B∪T) ≥ V(B∪S∖j)，所以 syn ≤ Δ_j(B∪S∖j) ≤ M_j^(|S|−1)。∎（不需要单调。随机博弈 20000 个零违例。）

- **强度若取 Möbius 红利则不成立**：V(i)=0.5（i=1,2,3），V(ij)=0.5，V(123)=1.0，m(123)=1.0，但 M^(2)=syn=0.5。
- 解读："不可约增益为 s 的 k 字段组合，其每个成员在 K=k−1 下 M 至少为 s"；反之不成立。

### 命题 7（估计误差传播与上下界）

设 Ṽ 为估计器（单调闭包后的 V_amortized），Δ̃ 为对应边际，e_i(T) = Δ̃_i(T) − Δ_i(T)。

(a) |M̃_i^(K) − M_i^(K)| ≤ max_{|T|≤K} |e_i(T)| ≤ 2 max_{|S|≤K+1} |Ṽ(B∪S) − V(B∪S)|；
(b) **下界**：对任意由估计器选出的背景 T̃（包括 T̃ = argmax Δ̃），L_i := Δ_i(B∪T̃) ≤ M_i^(K)。若 Δ 在独立审计数据上重训估计、T̃ 在认证前已固定，则 L_i 不含选择偏差；
(c) **上界**：令 T\* 为真值见证。若 e_i(T\*) ≥ −q，则 M_i^(K) ≤ M̃_i^(K) + q。所以只要对"见证类背景"的负向边际误差有 1−α 分位 q，就得到覆盖率 ≥ 1−α 的上界 U_i = M̃_i^(K) + q。

*证明*。(a) max 对 sup 范数 1-Lipschitz；边际误差 ≤ 两个价值误差之和。(b) 由定义。(c) M = Δ(T\*) = Δ̃(T\*) − e(T\*) ≤ M̃ + q。∎

- **关键**：(c) 需要的是**真值见证背景上的边际误差分布**。98/99 号显示估计器在强协同背景上系统性低估（尾部失明），所以不能用全体背景的误差分位代替，**必须按边际强度分层校准**。实验见 100 号 RQ3。
- 98 号的结论（边际误差比绝对价值误差更适合归因）在这里具体化为：M 的误差由**边际误差**控制。

## 5. K 的安全含义与推断升级曲线

K 不是模型超参数，而是**攻击者额外掌握的背景字段数量预算**。
- K=0：只考虑单字段；
- K=1：攻击者另有一个字段；
- K=|H|−1：攻击者掌握其余全部字段（即 MCI）。

建议报告每个字段的**推断升级曲线**（inference escalation profile）(M^(0), M^(1), M^(2), M^(3))，例如 0.08→0.71→0.76→0.77：单独很弱，只要一个辅助字段就大幅增强，并在低阶背景下迅速饱和。

选 K 的依据依次是：
1. 威胁模型（发布环境中攻击者可能额外获得的字段数）；
2. 经验饱和（M^(K) 相对 MCI 近似值的比例）；
3. 可认证性（见证背景能否在独立数据上复现）。

**不预设 K=2 最优**；99 号小博弈上 K=2 平均达到 MCI 的 92%，是否在完整字段集和 CAISO 上复现，由 100 号检验。

## 附录 A：与 Shapley 的对照分析（非主线）

**A.1 Harsanyi 表示**。令 m(U) 为 v_B 的 Möbius 变换，则 Δ_i(B∪T) = Σ_{U⊆T} m(U∪i)，φ_i = Σ_{U∋i} m(U)/|U|。
M^(K) 只取规模 ≤K+1、最坏组合、不分摊；Shapley 取全部阶、平均、按 |U| 分摊，并与冗余的负红利相抵。
99 号实例：风电出力 φ=0.035 = 0.058 + 14.12 − 14.14；M^(1) = 0.058 + 0.696。

**A.2 守恒型归因与单字段下界不相容**。若分数满足效率 Σs_i = v_B(H) 且对所有 i 有 s_i ≥ a_i^B，则 Σ a_i^B ≤ v_B(H)；存在冗余（Σa > v_B(H)）时不可能。这是 Catav 副本例子的一般化表述，**不作为本文主要贡献**。

**A.3 遮挡解析解**。V(S) = max(α·1[A∈S], β·1[x,y∈S])：α≥β 时 φ_x = β/6（无主通道时 β/2），而 M_x^(1) = β。99 号数值吻合。

**A.4 序关系**（单调时）：a_i/n ≤ φ_i ≤ MCI_i。
