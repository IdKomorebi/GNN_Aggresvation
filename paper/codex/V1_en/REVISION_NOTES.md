# 相对 paper/claude/V4_en 的修改说明

此稿是原 V4_en 的表达与展示优化版，不是另起研究工作的论文，也不是新的实验版本。

## 叙述主线

原稿同时较早引入三类审计问题、六项要求、MCI、安全裕量、关键性、MUS、扫描认证和全列预训练，读者需要先记住很多概念。新版优先回答一个问题：**单个字段的风险如何反映它在组合中的作用？**

1. **引言**：从同一物理系统产生的相关运行字段切入，用“价格 + 可再生预测 → 残余需求”说明组合问题；随后提出背景下的最大增益，最后引出大规模评估的计算困难。
2. **相关工作**：保留原有文献体系，围绕单字段评价、归因、推断图和多子集快速评估定位本文。
3. **问题与度量**：原 Problem Formulation 与 Field-Level Inference Risk 合并，先解释集合值，再定义字段的边际风险和见证，保留原有主要定理。六项要求表移至附录，减少主文的概念清单。
4. **计算方法**：以“共享表示、逐子集适配”为重点。图中将预训练与查询分成两行，主实验的目标监督与扩展的全列重构分开表述。
5. **实验**：四个 Results 章合并为组合风险、字段评价与扣留、估计精度与效率、鲁棒性与背景预算四节，避免每一组分析都像一个新的研究主题。
6. **讨论与结论**：围绕有解释的字段评价、组合搜索的效率及评价范围总结，不再重复整段实验结果。

## 英文与表述

- 标题从 Power Market Data 扩展为 Power-System Data，去掉冗长的双层标题结构。
- 删除 `We report this plainly`、`we state it explicitly`、`keeps it honest` 等对写作过程或作者态度的说明，直接给出结果及其含义。
- 将 `disposal` 统一改成更具体的 `withholding`，与本文实际采取的字段扣留操作一致。
- 清理“问题列表 → 贡献列表 → 再列问题”式重复。
- 摘要聚焦问题、核心量、计算方法与主要证据；全列预训练扩展不再与主方法争夺摘要篇幅。
- 保留随机主干、较低阈值下单字段排名较强、K=3 发现额外危险组合等原有发现，将其整合为解释性结果，而非研究日志。

少量范围性措辞同步简化：不再笼统宣称所有决策均经认证；将原训练数据使用句限定于模型拟合与超参数选择；在引用单调性性质时保留相应条件；将有方向性的低估表述为 predominantly downward errors。没有添加新的问题清单或实验要求，也没有开展方法修复。
