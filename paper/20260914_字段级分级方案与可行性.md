## 0. 一页结论

**目标**：给出一份**字段级**的推断风险分级表，它以推断为出发点，并且**显式容纳协同**。

**方案一句话**：在对数残差标度 `g(v) = −½ln(1−v)` 上，把集合风险分解为
**字段分数之和 + 一张稀疏的协同例外清单**，由集合级通用模型提供拟合所需的大量集合风险值，
由重训真值做认证与评估。

```
g(v_c(S))  ≈  Σ_{i∈S} w_{c,i}  +  max_{(i,j)⊆S} δ⁺_{c,ij}
           └─ 第一层：字段分数 ─┘   └─ 第二层：协同例外清单 ─┘
```

**预实验（69 号真值，12 个机密目标，全部为专门重训）已经确认的**：

| 问题 | 结论 | 关键数字 |
| --- | --- | --- |
| 标度选对了吗？ | **对数残差标度明显优于原始 R²** | 大集合留出：MAE 0.152 → **0.084**，Spearman 0.742 → **0.920** |
| 协同是稀疏的吗？ | **是** | 对数标度下 946 对 × 12 目标中，**87.9%** 近似可加，**6.7%** 协同，**5.3%** 冗余 |
| 只靠字段分数够吗？ | **不够**，在协同三元组上漏判明显 | 协同三元组留出：危险误判 **4.5%** |
| 加协同清单有用吗？ | **有用**，且聚合方式很关键 | 危险误判 4.5% → **0.7%**；"全部相加"在大集合上反而把危险误判拉到 3.8%，"取最大"不会 |
| 大集合上还有什么没解决？ | **冗余随集合变大而累积** | 字段分数在大集合上系统性高估：3–8 阶 +0.021，9–20 阶 +0.059，21–43 阶 **+0.115** |

**可行性判断**：**可行**，且主体工作量不大。风险集中在两处——
(1) 大集合区段的冗余校正需要大量中大规模集合的风险值，**这正是现有重训真值最稀缺、也是通用模型真正不可替代的地方**；
(2) 协同清单带来的危险误判下降，还需在**相同保守误判水平**下复核（预实验里保守误判同时上升了）。

## 1. 目标与问题定义

### 1.1 为什么还是要字段级

监管与业务实际使用的是**字段级**的分类分级表：每个字段一个等级，按等级决定能否对外发布。
集合级的结论（安全发布面、通道清单）在方法上更正确，但**落不进现有流程**。
所以本方案的定位是：

> **集合语义负责"算对"，字段级表格负责"用得上"；两者之间的差距被显式地量出来，并以一张短清单补上。**

### 1.2 被分级的量

- 字段全集 `F = G ∪ C`，`G` 为一般字段（44 个），`C` 为机密字段（12 个）。
- 对每个机密字段 `c ∈ C` 和任意发布集合 `S ⊆ G`：

```
v_c(S) = 攻击者拿到 S 的完整列数据后，专门针对 S 重训推断模型，对 c 所达到的最高测试 R²
```

- 性质：`v_c(∅) = 0`；在子集格上**单调不减**；`v_c ≤ 1`；在大集合上**饱和**。
- 阈值 `τ`（默认 0.7）：`v_c(S) ≤ τ` 视为可发布。

### 1.3 分级表应满足的要求

| 要求 | 含义 | 本方案如何满足 |
| --- | --- | --- |
| R1 以推断为出发点 | 分数必须来自攻击者重训语义，而非相关系数或专家打分 | 分数由 `v_c(S)` 拟合得到 |
| R2 可加可比 | 分数能直接相加/比较，用于判断一组字段 | 对数残差标度上可加，单位为奈特 |
| R3 空集为零 | 什么都不发，风险为零 | 标度自带 `g(0)=0`，常数项钉死为 0 |
| R4 单调 | 多发一个字段不会降低风险 | 字段分数非负；协同项只取正值 |
| R5 容纳协同 | 能表达"单看安全、合体泄露" | 第二层协同例外清单 |
| R6 可解释 | 每个分数、每条例外有明确含义 | 分数=信息份额；例外=被认证的字段组合 |
| R7 稳定 | 换一批抽样、换一年数据不翻转 | Bootstrap、跨设计、跨年检验（第 7 节） |
| R8 可落地 | 能离散成 3–5 个等级接入现行规范 | 第 3.6 节 |

## 2. 为什么字段级必须从集合语义里算

### 2.1 一个两行就能验算的反例

69 号真值（`total_gen` 目标）：

| 发布集合 | v | g(v) = −½ln(1−v) |
| --- | --- | --- |
| {风电出力} | 0.0638 | 0.0330 |
| {风电占比} | 0.1623 | 0.0886 |
| 两者之和（可加预测） | | 0.1215 |
| **{风电出力, 风电占比}** | **0.9277** | **1.3135** |

**可加预测比真值低约 10.8 倍，而且无法通过调权重弥合**：把两个字段分数抬高到能解释这一对，
两个单字段的预测就会崩。**没有任何一组 44 个数能同时满足这两类方程。**
物理原因很直接：总发电量 = 风电出力 ÷ 风电占比。

### 2.2 由此得到的立场

1. **v 本来就不可加**，所以字段分数 `w` 不是自然界里存在的参数，而是一个**投影**。
2. 论文不去找"正确的 w"，而是说明**投影到哪**、并**报告投影后剩下的部分**。
3. 剩下的部分在绝大多数字段对上很小（87.9% 近似可加），集中在少数对上——
   所以它**可以用一张短清单补上**，而不需要放弃字段级格式。

这三点就是本方案的全部逻辑。

### 2.3 与"集合级安全发布面"的关系

- 字段级阈值规则（发布所有等级 ≤ ℓ 的字段）只能表达格上的一个"子立方体"。
- 字段分数之和 ≤ 阈值，能表达的形状比子立方体丰富，但仍然只能是"半空间型"的下闭集。
- 真实可发布域是任意下闭集。

**三者的差距可以逐级量出来**——这正是第 8 节评估的骨架。

## 3. 分级模型

### 3.1 标度：对数残差

```
g(v) ≜ −½ · ln(1 − v)          （实现时 v 截断到 [0, 1−10⁻³]）
ĝ⁻¹(x) = 1 − e^{−2x}
```

**理论依据**：若机密量与发布字段联合高斯，`I(X_S; Y) = −½ln(1 − R²_S)`，
即 `g(v)` 就是**互信息（奈特）**。在该标度上：

- 可加 ⟺ 各字段提供的是**互相独立**的信息；
- 实际 > 可加预测 ⟺ **协同**（合体产生了各自没有的信息）；
- 实际 < 可加预测 ⟺ **冗余**（字段之间信息重叠）。

非高斯、非线性攻击者下，`g(v)` 不再严格等于互信息，但仍是"有效信息量"的自然度量，
且保留 R3/R4 与不越界这三条硬性质。论文里如实写"高斯情形下精确，一般情形下作为有效信息量"即可。

**预实验验证**：在 3–43 阶随机大集合（留出，未参与拟合）上，同样的非负可加拟合：

| 标度 | MAE | 偏差 | Spearman |
| --- | --- | --- | --- |
| 原始 R² | 0.152 | +0.147 | 0.742 |
| **对数残差** | **0.084** | **+0.071** | **0.920** |

原始标度上字段分数一加就越过 1、被截断，排序信息丢失；对数标度上饱和被吸收进了标度本身。

### 3.2 第一层：字段分数

```
g(v_c(S)) ≈ Σ_{i∈S} w_{c,i}，    w_{c,i} ≥ 0，    无常数项
```

- **求解**：非负最小二乘（NNLS），可加岭正则 `λ‖w‖²` 防止个别系数飞掉。
- **单位**：奈特。`w_{c,i}` = 字段 i 对机密量 c 平均贡献的有效信息量。
- **常数项为何不要**：`v(∅)=0 ⟹ g(v(∅))=0`，空和也为 0，所以常数项被定义钉死。
  若放开拟合得到显著非零的常数，那是**模型失配的诊断量**，应作为检查项报告，而不是作为参数保留。
- **单调性**：`w ≥ 0` 保证多发字段不降风险。

### 3.3 第二层：协同例外清单

对每个字段对定义**对偶残差**：

```
δ_{c,ij} = g(v_c({i,j})) − w_{c,i} − w_{c,j}
```

- `δ > 0` 为协同，`δ < 0` 为冗余。
- **清单只收录显著协同**：`δ⁺_{c,ij} = δ_{c,ij}`，当 `δ_{c,ij} > θ_δ`（预实验取 0.05 奈特）且经重训认证；否则为 0。
- **聚合方式：取最大，不求和**：

```
Ĝ_c(S) = Σ_{i∈S} w_{c,i} + max_{(i,j)⊆S} δ⁺_{c,ij}
```

**为什么是取最大**——这是预实验里最重要的一个细节：

| 聚合方式 | 协同三元组（留出） 危险误判 | 大集合（留出） MAE | 大集合 危险误判 |
| --- | --- | --- | --- |
| 仅字段分数 | 4.5% | **0.084** | 0.6% |
| + 所有对的 δ 相加（含负值） | 0.8% | 0.112 | **3.8%** |
| + 显著协同相加 | 0.7% | 0.098 | 0.6% |
| **+ 显著协同取最大** | **0.8%** | **0.090** | **0.6%** |

大集合里包含几十上百个字段对，把所有 `δ` 都加上，冗余项（负值）会成片抵消风险，
**反而制造出假安全**（危险误判从 0.6% 升到 3.8%）。只收正值并取最大，
在协同三元组上拿到同样的收益，同时不破坏大集合。

**解释**：一个发布集合里只要有**一条**强协同通道，攻击者就能利用它；
多条通道的信息高度重叠（都指向同一个机密量），不应线性累加。取最大正对应"攻击者走最强的那条路"。

### 3.4 冗余校正（大集合区段，待定形式）

预实验显示字段分数在大集合上**系统性高估**，且随集合增大而加重：

| 集合规模 | 样本数 | 平均高估 |
| --- | --- | --- |
| 3–8 | 168 | +0.021 |
| 9–20 | 132 | +0.059 |
| 21–43 | 228 | **+0.115** |

方向是**保守的**（高估风险，不会漏判），但它会让分级表在大规模发布时过度拒绝。候选校正形式：

| 形式 | 写法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 规模收缩 | `Ĝ = (Σw) · h(|S|)`，`h` 单调递减 | 一个一维函数，易解释 | 与字段无关，粗糙 |
| 冗余组 | 把强冗余字段聚成组，组内取最大、组间相加 | 物理可解释（同源量测归一组） | 需要额外聚类步骤 |
| 负对清单 | 与协同清单对称，收录显著冗余对 | 形式统一 | 大集合上累加仍会过校正 |

**建议**：第一篇采用**冗余组**，因为电力字段天然有同源结构（同一燃料的出力/占比、日前/实时同名量），
分组可以先由关系剥离层给出初值，再由数据修正。**这一步必须等通用模型补齐中大集合的风险值后才能定型**
（见 11.3），因为现有真值在 9 阶以上每个目标只有约 40 个集合。

### 3.5 最终发布规则

```
可发布(S)  ⟺  ∀c ∈ C：  ĝ⁻¹( Ĝ_c(S) )  ≤  τ − m
```

`m` 为经保守程度对照标定的余量。一个集合要能发布，必须对**所有**机密字段都安全。

### 3.6 离散成等级（对接现行分类分级规范）

1. **多目标汇总成一个字段分数**：`W_i = max_c w_{c,i}`（安全取向：看该字段对最敏感目标的贡献）；
   同时保留 `argmax_c`，即"该字段主要威胁哪个机密量"。
2. **按信息量分档**：以 `ĝ⁻¹` 映射回 R² 口径设档，例如
   L1 `W < g(0.05)`、L2 `< g(0.2)`、L3 `< g(0.5)`、L4 `≥ g(0.5)`；也可按分位数分档，二者在论文中都报告。
3. **协同清单单独成表**：`(字段 i, 字段 j, 受威胁机密量 c, δ, 认证 R²)`。
   规范上表述为"下列字段组合即使各自等级允许，也不得共同发布"。

最终交付物是**一张分级表 + 一张共发禁令表**。这是现行规范能直接吸收的格式。

### 3.7 两种字段分数：归因版与预测版

| | 预测版 `w^LS`（默认） | 归因版 `w^Sh`（Shapley 核） |
| --- | --- | --- |
| 求法 | 分层设计上的 NNLS | 权重 `π(S) ∝ 1/[|S|(n−|S|)]` 的加权最小二乘（KernelSHAP 表述） |
| 回答 | "用分数之和判断一组字段，最准的是哪组分数" | "全量发布的总泄露，公平地摊到每个字段上各是多少" |
| 性质 | 直接服务发布规则 | 效率性：`Σ_i w^Sh_i = g(v(G))`；单调博弈下自动非负 |
| 依赖 | 设计分布 | 需要覆盖**所有规模**的集合，尤其是很大的集合 |
| 用途 | 分级表、发布规则 | 解释"每个字段占总风险的份额"；与 SPVIM 对接 |

**第一篇以预测版为主**，归因版作为"份额解释"的补充。
注意归因版对大集合的依赖更强，现有真值撑不起，**必须由通用模型提供**。

## 4. 多机密字段的处理

12 个机密字段、44 个一般字段 → 分数矩阵 `W ∈ ℝ^{44×12}` 与每个目标一张协同清单。

- **逐目标独立拟合**：不同目标的推断机制不同（电价 vs 功率 vs 损耗），不共享参数。
- **汇总规则**：字段等级取 `max_c`；协同清单取并集并标注目标。
- **可视化**：44×12 热力图（行=一般字段，列=机密字段），配合聚类，一眼看出"哪类字段主要威胁哪类机密量"。
  这张图对电力读者很有说服力。
- **目标间一致性检查**：物理上相关的目标（如 `total_lmp_da` 与 `congestion_price_da`）的字段分数应高度相关；
  若不相关，要检查是否是估计问题。

## 5. 设计：选哪些集合、选多少、怎么找

### 5.1 拟合集：预先登记的分层设计

| 层 | 取法 | 每目标数量 | 作用 |
| --- | --- | --- | --- |
| 单字段 | 穷举 | 44 | 锚定字段分数 |
| 字段对 | 穷举 | 946 | 锚定对偶残差 δ，协同清单的来源 |
| 3 阶 | 均匀随机 | 2 000 | 检验两层模型 |
| 4–8 阶 | 每阶均匀随机 | 5 × 2 000 | 冗余开始累积的区段 |
| 9–20 阶 | 分段均匀随机 | 3 000 | **冗余校正的主要依据** |
| 21–43 阶 | 分段均匀随机 | 3 000 | 饱和区段，校正规模函数/冗余组 |
| 全集 | 必取 | 1 | 归因版的效率性锚点 |

合计每目标约 **2 万个集合**。

### 5.2 不要偏向协同集合

**拟合时不偏向协同。** 若多选协同集合，第一层会把协同吸进字段分数——
`w` 被整体抬高，第二层清单变短，"字段级能表达多少"这一结论同时被污染。
**协同集合只放进评估集**，用来报告两层模型在协同区域的表现。

预实验里的做法与此一致：拟合只用单字段 + 字段对 + 随机三元组，
协同偏向的 `triple_top` 与大集合 `wide_random` 全部作为留出评估。

### 5.3 选多少：用信息曲线和 bootstrap 定

- **逐层信息曲线**：横轴规模 k，纵轴该层内 `g(v)` 的方差。方差塌缩处即饱和起点，此后减少采样。
- **Bootstrap 停止准则**：逐步增加每层样本，直到所有字段分数的 95% 置信区间宽度小于相邻两个等级的间距，
  且协同清单的成员不再变化。
- 以上两条都要**多次重跑拟合**，这是查询必须便宜的直接原因之一（第 11.3 节）。

### 5.4 协同清单怎么找

1. **字段对**：946 个穷举（通用模型 ~2 秒/目标）→ 按 δ 排序 → 取 `δ > θ_δ` 的候选。
2. **认证**：候选对逐条重训，保留认证后仍满足阈值者。现有 91 号已有 946 对 × 12 目标的重训真值，**可直接复用**。
3. **三阶例外（可选）**：只在三阶残差 `g(v_{ijk}) − Ĝ(ijk)` 仍显著时加入。
   候选生成用头顶空间剪枝 `syn(S) ≤ 1 − max_{T⊊S} v(T)` + 束搜索；
   漏检用均匀随机抽样给出置信上界（m=10⁵ 时五阶最多漏 33 个，见 0913 纪要第 7 节）。
4. **清单长度本身是结论**：若二阶清单就把协同区域的危险误判压到可接受水平，
   就说明"**分级表 + 两两禁令**已经够用"，这是可以直接执行的政策建议。

## 6. 估计：通用模型怎么用

| 环节 | 用什么 | 说明 |
| --- | --- | --- |
| 拟合集的 `v` 值 | 通用模型（闭式读出，L0 或 L1） | 每目标 ~2 万次；L0 约 2.5ms/次 → ~50 秒 |
| 协同候选排序 | 通用模型 | 只负责排序，不负责定论 |
| 协同清单入选 | **重训认证** | 红线：清单成员必须经重训确认 |
| 评估集的 `v` 值 | **重训真值** | 红线：评估不能用估计值，否则循环论证 |
| 保守余量 `m` | 在评估真值上用保守程度对照标定 | 与 `diantan` 的 `match_control.py` 同一协议 |

**方法学红线（沿用）**：重训真值只用于评估与认证，绝不进入拟合或查询路径。

### 6.1 估计误差会怎样传到分级里

- 通用模型在**强协同集合上系统性低估**（尾部失明），这会让 δ 偏小、协同清单漏项。
  → 协同候选的阈值要放宽（先多收后认证），不能用估计值直接截断。
- 在**普通集合**上通用模型较准，字段分数主要由普通集合决定 → 第一层对估计误差不敏感。
- **需要的检验**（第 9.2 节）：用真值拟合的分级 vs 用估计拟合的分级，二者的 Kendall τ 与等级变动数。

## 7. 可辨识性与稳定性

### 7.1 不会"多解"

2 万个方程、44 个未知数，严重超定；设计矩阵行是 0/1 指示向量，混合规模采样必然满秩。解唯一。

### 7.2 真正的风险：解随设计而变

因为 v 不可加，换一个采样分布就换一个投影。必做三项：

1. **Bootstrap 置信区间**：每个 `w_{c,i}` 给区间；跨越相邻等级的字段标"边界"。
2. **跨设计一致性**：三种设计（本方案分层 / 按规模均匀 / Shapley 核）各拟合一次，
   报告两两 Kendall τ。**τ > 0.9 视为稳健**；达不到如实报告，并说明哪些字段敏感。
3. **跨年一致性**：`pjm_2024` 与 `pjm_2025` 字段名完全一致，各自拟合一份分级，报告 Kendall τ
   与协同清单的重合率。**一份年年翻转的分级表不能用于监管**，跨年稳定是最强的有效性证据之一。
   （注意：两份数据在 `diantan/data_rule/` 下是 69 列口径，需先映射到本文的 44/12 字段划分。）

### 7.3 常数项作为失配诊断

另拟合一版带常数项的模型。若常数显著非零，说明对数标度下仍有系统性曲率未被吸收——
报告出来，作为引入冗余校正的依据。

## 8. 怎么判断分级是合理有效的

**前提**：不存在"真值分级"，所有评估都必须是**任务化**的——分级好不好，看它能不能支撑正确的发布决策。

### 8.1 主判据：决策一致性（在相同保守程度下比较）

在**重训真值评估集**上，比较分级规则（3.5 节）与真值 `v ≤ τ` 的判定：

- **危险误判率**：规则判可发布、真值超阈；
- **保守误判率**：规则判不可发布、真值安全。

两者此消彼长，**任何整体抬高风险的改动都会降低危险误判**。所以必须：
给每个方法的估计加一系列偏移，画（保守误判，危险误判）曲线，**在相同保守误判水平上横比**。
这一协议在 `diantan/sampling_lab/match_control.py` 已有实现，曾一轮推翻三个"看着很好"的结论。

> ⚠️ 预实验中协同清单把危险误判从 4.5% 降到 0.8%，但保守误判从 2.4% 升到 3.8%，
> **尚未做保守程度对照**，这是下一步的第一件事。

### 8.2 扣留曲线（排序是否正确）

按分级从高到低**扣留**前 k 个字段，重训测剩余字段的 `v`，画 k–v 曲线：下降越快越好。
对比：随机序、单字段 R² 序、相关系数序、IGNN 序、本文字段分数序、本文"分数 + 清单"序。
方法论上对应 ROAR（Hooker 等 NeurIPS 2019）的"删除后重训"。
用"扣留最危险的"而不是"发布最安全的"，因为前者是安全语义。

> 注意：扣留曲线只评价**排序**，看不出协同清单的价值（清单不是排序）。它是辅助指标，不是主判据。

### 8.3 监管形态检验（最贴近实际用法）

把分数离散成 3–5 个等级，执行"发布所有等级 ≤ ℓ 的字段"，对每个 ℓ：

- 报告真实 `v`（每个机密目标）；
- 列出该发布集合里命中的协同清单条目；
- 对比"不带清单"与"带清单"两种执行方式。

**这张表本身就是论题的证据**：它会直接展示"按字段等级看完全合规、实际因协同而泄露"的具体例子。

### 8.4 分层报告

所有指标**按集合规模和集合类型分层**报告，至少分：随机小集合（3–8）、随机大集合（9–43）、协同偏向集合。
预实验已经显示三个区段的误差机制完全不同，混在一起报告会掩盖问题。

### 8.5 负对照

把机密列打乱顺序后重拟合分级，它在 8.1–8.3 上都应不优于随机序。几乎不花算力。

## 9. 基线与对比实验

### 9.1 分级方法的基线

| 基线 | 做法 | 需要的查询 | 预期 |
| --- | --- | --- | --- |
| B0 相关系数分级 | 字段与机密量的 \|相关\| | 0 | 最弱；不含非线性与协同 |
| **B1 朴素单字段分级** | `w_i = g(v({i}))` | **44 次重训** | 主效应上**几乎与拟合一样好**（预实验）；无协同能力 |
| B2 IGNN | 按原论文复现 | — | 字段级、固定模型传播 |
| B3 拟合字段分数（第一层） | 本文 3.2 节 | 2 万次估计 | 大集合略优于 B1，协同区漏判 |
| **本文 两层分级** | 3.2 + 3.3 (+3.4) | 2 万次估计 + 清单认证 | 协同区危险误判大幅下降 |
| B4 全两两模型 | 所有 δ 相加 | 同上 | 协同区好，**大集合假安全**（预实验 3.8%） |
| 上界 集合级判定 | 直接用 `v(S)` | 每个集合一次 | 分级方法不可能超过它 |

B4 与"上界"两行很重要：前者说明**不是加得越多越好**，后者给出字段级格式与集合级方法之间的距离。

### 9.2 通用模型本身的对比

落点放在**分级结果**上，而不是估计器误差：

| 估计器 | 已有数据 | 本文要补的 |
| --- | --- | --- |
| 普通随机遮蔽 + 共享读出 | 尾部排序 0.130，全局 0.606 | 由它拟合出的分级 |
| + 仿射校准 | 尾部 0.199 | 同上 |
| + 查询期微调 K 步 | 50 步 ρ=0.899，55.5 ms/次 | **微调多少步，分级才与 L0 一致**；总耗时 |
| L0 零训练闭式读出 | ρ=0.904，2.5 ms/次（22.4×） | 分级 |
| L1 元训练闭式读出 | 尾部 0.858 | 分级 |
| **重训真值（参照）** | — | 仅在评估集规模可承受的范围内 |

每个估计器报告：与真值分级的 **Kendall τ**、**有几个字段移动 ≥ 2 个等级**、协同清单的**召回与精确率**、
第 8 节指标的差异。
"用共享读出会让 X 个字段评错等级、漏掉 Y 条协同禁令"比"MAE 从 0.11 降到 0.04"更有说服力。

### 10.4 解读，以及对 0913 纪要的修正

1. **对数残差标度成立。** 大集合上误差减半、排序从 0.74 升到 0.92。0913 纪要 A.1 的前提得到确认。
2. **协同稀疏且可清单化。** 仅 6.7% 的字段对显著协同——"字段分数 + 短清单"的两层结构有数据支撑。
3. **字段分数单独使用会在协同区漏判**（4.5%），**加清单后降到 0.8%**。这是本方案的核心证据，
   但保守误判同步上升，**必须补做保守程度对照**才能下结论。
4. **"全部相加"会在大集合上制造假安全**（0.6% → 3.8%），**"只收协同、取最大"不会**。聚合方式不是细节。
5. **修正一：朴素分级在主效应上并不差。** 朴素（44 次单字段重训）与拟合的字段分数在两个留出集上几乎一样
   （大集合 0.089 vs 0.084；协同三元组 0.077 vs 0.059）。0913 纪要 A.6 中"朴素分级会错得离谱、
   它的失败就是必须上通用模型的全部理由"——**这个论证不成立，已撤回**。
   朴素分级真正的缺陷不在字段分数本身，而在于**它没有第二层、也没有大集合冗余校正**。
6. **修正二：头条数字要换。** 0913 纪要里"可加模型只能解释 62% 的变异"是示意，实测小集合上约 0.93。
   **论文头条不应是"可加模型解释力低"，而应是"协同区域的危险误判能被一张短清单降到原来的约 1/5"**
   （待保守程度对照确认），以及"冗余随规模累积，字段级格式在大规模发布时系统性过度拒绝"。
7. **局限**：大集合每目标仅约 44 个、12 目标合计 528 个；协同三元组是按估计值偏向选取的，不是无偏样本。
   这些结论是方向性的，定量结论需在第 12 节的正式实验中复现。

### 11.3 通用模型的必要性（修订版）

预实验把必要性论证的落点改掉了。按分级方案的三个组成部分分开看：

| 组成部分 | 需要的集合 | 纯重训可行吗？ | 通用模型的作用 |
| --- | --- | --- | --- |
| 第一层字段分数 | 主要由小集合决定 | **可行**（朴素 44 次就接近拟合结果） | 不是必需，不要在这里宣称必要性 |
| 第二层协同清单 | 946 对/目标 | 勉强可行（~8 小时/目标，12 目标 4 天） | 排序与候选生成，节省数天 |
| **大集合冗余校正** | **每目标数千个 9–43 阶集合** | **不可行**（~1 天/目标，且需多次重跑） | **不可替代** |
| **稳定性诊断** | bootstrap、跨设计、跨年，每项都要全流程重跑 | **不可行** | **不可替代** |
| 归因版（Shapley 核） | 必须覆盖极大集合 | 不可行 | 不可替代 |

**修订后的必要性论证**：

> 字段分数的主效应用 44 次单字段重训就能得到，这不需要通用模型。
> 但字段级分级真正的误差不在主效应，而在两处：**协同**（集中在少数字段对）与**冗余**（随发布规模累积）。
> 前者需要逐对排查，后者需要大量中大规模集合的风险值——而这恰是重训成本最高、现有真值最稀缺的区段
> （69 号真值在 9 阶以上每个目标仅约 40 个集合）。
> 更重要的是，一份能用于监管的分级表必须附带置信区间与稳定性检验，而每一项检验都要求把整套拟合重跑一遍。
> **通用模型的价值不在于替代某一次重训，而在于让"带误差棒的、覆盖全规模的"分级在工程上可做。**

这个版本比"朴素分级会错得离谱"更诚实，也更难反驳。

## 13. 在论文里怎么写

### 13.1 定位句

> 本文提出一种**以推断为出发点、显式容纳协同**的字段级数据分级方法：
> 在有效信息量标度上把集合级推断风险分解为字段分数与稀疏协同例外，
> 由集合级通用估计模型提供覆盖全规模的风险值，由重训真值完成认证与评估。

### 13.2 贡献表述（建议）

1. **分级模型**：对数残差标度下的两层字段级分级（字段分数 + 协同例外清单），给出信息论解释
   （可加 ⟺ 独立信息；超/亚可加 ⟺ 协同/冗余），并说明协同项应取最大而非求和。
2. **量化证据**：字段分数单独使用在协同区域漏判、在大规模发布时系统性过度拒绝；
   两层结构在相同保守程度下显著降低危险误判；协同在字段对中仅占约 7%，清单短而可执行。
3. **方法**：以集合级通用模型提供拟合所需的全规模风险值，配合预先登记的分层设计、
   重训认证红线与稳定性诊断，使"带置信区间的分级表"在工程上可做。
4. **验证**：两个真实电网数据集、跨年稳定性、监管形态检验与多类基线（含 IGNN）。

### 13.4 必须主动写明的局限

- `g(v)` 仅在高斯情形下严格等于互信息；
- 分级是投影，结论依赖设计分布（已用跨设计一致性检验）；

- 风险度量为给定攻击者族下的 R²，业务阈值需结合场景设定。
