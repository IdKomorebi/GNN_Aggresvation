## 1. 设置

- **字段**：PJM 44→41、CAISO 44→41 去别名（精确/仿射副本合并，近重复保留）；12 个目标；数据切分沿用 69/95 号，train 内 15% 为 val。
- **真值**：并行专用重训 DNN（val 选轮次）规模 ≤4 全部集合（seed0），规模 ≤3 另跑 seed1；梯度提升树规模 ≤3（sklearn HistGBDT，val 选轮次）。
- **经验攻击能力的单调闭包**：在 val 上选子集、test 上报告。非单调占比（闭包−原值>0.01）PJM 1.7%、CAISO 0.04%。
- **估计器**：L0ensx（主）、L0、L1x（仅 PJM）、direct，规模 ≤4 全部集合。

## 2. 真值侧：升级曲线、K 敏感性、攻击器、噪声

**升级曲线**（41 字段 × 12 目标 = 492 条，DNN 真值）：

| | PJM | CAISO |
| --- | --- | --- |
| 平均 M^(0)→M^(1)→M^(2)→M^(3) | 0.135→0.226→0.261→0.282 | 0.177→0.246→0.266→0.277 |
| K 阶相对前一阶增益 >0.02 的条目 | K=1 84%，K=2 58%，K=3 36% | 85% / 44% / 17% |
| 相对单字段升档（档位 0.05/0.2/0.5） | K=1 49%，K=2 63%，K=3 71% | 35% / 46% / 53% |
| 排序 Kendall（M^(K) vs 单字段） | 0.64 / 0.58 / 0.55 | 0.83 / 0.80 / 0.78 |

**形状统计**：增强主要在 K=1 完成 PJM 80 条 / CAISO 117 条；在 K=2 完成 217 / 239 条；延续到 K=3 180 / 106 条（多为弱字段，M^(3) 均值 0.17）；有推断能力但无背景增强 10 / 17 条。

**典型案例**（图2）：
- PJM：K=1 增强最大的 12 条全部是同燃料"出力 + 占比"对，目标为总发电或计量负荷。例如风电出力 0.06→0.76、光伏出力 0.01→0.60。机制是 total = mw / pct。
- CAISO：
  - 实时 LMP（NP15 与 SP15 互为见证）→ 实时 SP15 阻塞价（0.04→0.38；节点价差≈阻塞分量）；
  - SP15 光伏日前预测 + 南区负荷计划 → CA ISO 实际负荷（0.08→0.40，净负荷关系）；
  - 日前节点价 + 光伏预测 → 日前发电计划。

**攻击器**（DNN vs DNN ∪ 树，val 选择）：

| | PJM K=0/1/2 | CAISO K=0/1/2 |
| --- | --- | --- |
| M 平均绝对差 | 0.011 / 0.021 / 0.029 | 0.007 / 0.010 / 0.015 |
| Kendall | 0.88 / 0.85 / 0.82 | 0.94 / 0.93 / 0.91 |
| 档位一致 | 93% / 91% / 87% | 97% / 96% / 92% |
| 见证身份一致 | 100% / 62% / 31% | 100% / 67% / 40% |
| τ=0.7 关键字段数（12 目标合计） | 11→11 / 84→114 / **220→334** | 18→18 / 136→136 / 217→226 |

⟹ **字段排序与档位对攻击器基本稳定，阈值跨越不稳定（PJM）**。论文中的经验攻击能力必须用攻击器族取最大。

**种子噪声**（DNN seed0 vs seed1，规模 ≤3）：|ΔM| PJM 0.002/0.003/0.005、CAISO 0.001/0.002/0.003；Kendall ≥0.96；见证身份一致 PJM 82%/63%、CAISO 79%/58%（K=1/2）。

## 3. 近似 full-MCI 与饱和（图1）

对每个 (字段, 目标)，用通用模型 L0 贪心扩展背景到 12 个字段，再加 600 个随机排列前驱背景，取 4 个候选大背景做专用重训认证。
MCI_lower = max(M^(3), 认证值)，是 MCI 的**已认证下界**，所以饱和比是上估。

| 饱和比 M^(K)/MCI_lower | PJM 均值 / 中位 / ≥0.9 占比 | CAISO |
| --- | --- | --- |
| K=0 | 0.39 / 0.35 / 5% | 0.51 / 0.52 / 10% |
| K=1 | 0.71 / 0.75 / 24% | 0.81 / 0.85 / 39% |
| K=2 | **0.88 / 0.93 / 57%** | **0.93 / 0.97 / 75%** |
| K=3 | 0.999 / 1.00 / 99.8% | 0.999 / 1.00 / 99.8% |

- 大背景认证边际超过 M^(3) 0.02 以上：两数据集都是 0.2%，最大超出 0.03。
- ⚠ PJM 上 L0 对大背景边际高估 +0.068（MAE 0.09），CAISO +0.008；大背景真值未做单调闭包。
- 一致性（命题 5b）：98 号 14 人博弈的 13 个共同字段在全集上 M^(K) 更大（K=1/2/3 +0.016/+0.037/+0.053），K≥2 无违例。所以小博弈的饱和比在全集上必然下降。

## 5. 公开基底场景（PJM，图6）

B = {最新负荷预测, 日前负荷预测}（PJM 官方公开发布）。
- V(B)：total_gen 0.974、metered_load 0.991 → **基底泄露**，这两个目标的字段分级失去意义；
- 其余目标给定 B 后最大 M^(2) 普遍下降，例如 total_lmp_da 0.983→0.406、marginal_loss_price_da 0.682→0.303、total_losses 0.621→0.267；
- 净交换功率、备用类目标几乎不变；
- M^(2) 字段排序 Kendall（B=∅ vs 给定 B）0.47–0.87。

## 6. 效率（对最强基线，图7）

**结论（限定）**：在 41 个字段上，K≤2 用并行专用重训十几分钟就能精确完成，**通用模型不是必需的**。
通用模型的时间优势（L0 相对并行重训约 24×，L0ensx 约 2×）只在以下场景才实质：
- 完整 K=3（10⁵ 查询）；
- 字段数更大（按集合数外推，p=100 时完整 K=2 并行重训约 2.6 小时、L0 约 7 分钟）；
- MCI 大背景搜索；
- 更换基底 B、数据快照或目标时反复重算；
- 交互式审查。

而且 L0 的 M 精度弱于真值（PJM K=2 召回 52%），所以速度优势必须和"L≤M≤U 区间 + 重训认证关键见证"一起使用。

## 7. CAISO 副本 / 备用通道对照（gameC，图8）

14 个字段：分区负荷预测 ×4、分区负荷计划 ×3、节点电价 ×4、SP15 光伏实际/预测、调节下调需求。2^14 联盟全枚举真值；全量模型 SAGE（边际填补）用 3 个种子。

| 目标（v(全集)） | Shapley vs M^(1) Kendall | SAGE vs Shapley | SAGE vs M^(1) | SAGE 种子间 | 强字段 Shapley/a | 强字段删除边际 |
| --- | --- | --- | --- | --- | --- | --- |
| CA ISO 实际负荷（0.96） | 0.82 | 0.59 | 0.65 | 0.89 | 0.16 | 0.001 |
| 日前发电计划（0.95） | 0.87 | 0.42 | 0.42 | 0.93 | 0.16 | 0.002 |
| SP15 日前 LMP（0.99） | 0.87 | 0.21 | 0.12 | 0.89 | 0.12 | 0.002 |
| 日前下调调节采购（0.98） | 0.85 | 0.40 | 0.39 | 0.82 | 0.23 | 0.046 |

案例（SP15 日前 LMP）：
- ZP26 日前 LMP 与 SP15 日前能量价单字段各为 0.96，总体 Shapley 各只有 0.14，M^(1) 为 0.96；
- 全量模型 SAGE 把重要性集中到这两个字段（0.37/0.50），而同样单字段可推 0.87 的 SP15 实时 LMP、0.77 的 NP15 日前 LMP，SAGE 只有 0.06 / −0.06。

⟹ 与 98/99 号 PJM 结果一致：
- **model reliance ≠ potential inference capability**：全量模型只依赖被它选中的替代通道；
- **fair allocation ≠ disclosure hazard**：Shapley 把强副本平均分摊，删除边际把它们全部判为 0。

这里只作为对照，不作为主线。

## 8. 局限

- 真值攻击器族为 DNN + 一种树模型；XGBoost/LightGBM 未安装，未做；RF 未做。
- 大背景（≥4 字段）的认证只覆盖通用模型挑出的候选，MCI 只有下界。
- 同表认证存在选择偏差，独立数据认证见 101 号。
- 上界的覆盖保证依赖"留一字段"的可交换性假设，不是有限样本严格保证。
