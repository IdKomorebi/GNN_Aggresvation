# 认证与统计协议技术报告（供第二数据集复刻）

数据背景：PJM 数据集，44 个 general 字段、12 个 confidential 字段，`v_c(S)` = 攻击者仅持字段子集 S 时对机密字段 c 的重训 DNN 测试集 R²。以下所有编号目录均在 `/data1/duhaocun/projects/GNN_Aggresvation/` 下。

## 1. DNN 重训认证标准协议（88 号修正后版本）

参考实现（逐字沿用即可）：
- `DNN_Aggresvation88/scripts/retrain_worker.py`（修正版 worker）
- `DNN_Aggresvation93/scripts/certify_highorder.py`（高阶认证完整流程，含 syn 配对）
- `DNN_Aggresvation88/scripts/build_split_cache.py`（三分割缓存）

**专用模型架构**（`DNN` 类，93 号注明"逐字沿用 88 号"）：
- MLP：`Linear(n_in,128) → ReLU → Dropout(0.15) → Linear(128,128) → ReLU → Dropout(0.15) → Linear(128,12)`；输入只有子集 S 的原始列（不做掩码拼接），输出 12 个 conf。
- 优化：Adam lr=1e-3, weight_decay=5e-4, batch=128, EPOCHS=400, PATIENCE=120。

**数据切分（三层，全部固定种子）**：
1. 全数据 → train/test：`prepare_data(cfg)`，切分种子固定 42（`torch.manual_seed(42); np.random.seed(42)` 后再 prepare），保证与全项目历史真值同口径。
2. 原 test（1967 行）→ **search(983) / audit(984)**：`np.random.RandomState(SPLIT_SEED=880725).permutation` 前后各半。这是 88 号修正 #1：任何结构化估计器/beam 的自适应搜索只许用 search 分片；**audit 只在最终报数时用一次**。
3. train 内部 → fit/val：固定 `torch.Generator().manual_seed(20260725)`，切 15% 作 validation。

**早停指标**（88 号修正 #2，最关键的一条）：每个 epoch 在**训练集内部 15% val 上算全 12-conf 平均 MSE**，取最优权重快照，PATIENCE=120 轮无改善则停。测试集在训练函数内**完全不被读取**（旧版用测试集 MSE 早停，污染了 67/68/77/86 共用的整套"真值"，必须避免）。

**seed 策略**：认证重训用单 seed（`--seed 0` 控制模型初始化/dropout/batch 顺序）；合法性依据是 60 号测得的噪声底 σ（DNN ≈0.0015、GCN ≈0.0039），显著性标尺：12-conf 平均口径差异 >0.01（DNN）/>0.02（GCN）才算数。数据切分种子永远是 42，不随 seed 变。

**v(S) 与最强父集 v(T) 的配对、syn 计算**（`certify_highorder.py`）：
- 对每个 m 阶集合 S：重训 1（S 自身）+ m（全部 m−1 阶子集）个专用 DNN（order-5 即 6 个模型，实测 ~160–180 s/集合）。
- 逐 conf 计算 `inc_c = v_c(S) − max_{T⊂S,|T|=m−1} v_c(T)`（注意 max 在**同一 conf 内**跨子集取，父集不预选，全部子集都重训）。
- `syn_true = max_c inc_c`（另单独记录"结构化估计器所选 conf 上的 syn"作对照列）。
- R² 报两套：audit 分片（与结构化扫描可比）与全 test（与历史真值可比）；`per_conf_r2` 做 `clip(·,0,None)`。
- **认证实验必须带随机对照组**（弱估计值集合随机抽 20 个走同一流程），用 Mann–Whitney U 单边检验强组是否真的强于对照——93 号正是靠这个发现 full 字典的 441 个"强五阶"与随机无差异（p=0.058）。
- 附带诊断列："子集反超"（某子集 v 反而高于全集，即 syn 真值为负的证据）。

## 2. 配对 FDR 检验（93 号任务 C）

实现：`DNN_Aggresvation93/scripts/paired_fdr.py`。

**统计量构造**：
- 基于冻结 oracle 特征 φ + 闭式岭读出（91 号），S 与其父集 T 的预测误差来自**同一个 φ、同一批 audit 样本**，可逐样本配对；闭式解无优化噪声（微调则两边各带独立初始化/批序噪声，差分方差放大 √2）。
- 逐样本配对差：`d_i = err²_T(i) − err²_S(i)`（同一 audit 样本 i，同一 conf c）。
- `syn = mean(d)/Var(Y_c)`（即配对版 R² 差点估计）；`se = sd(d,ddof=1)/√n_audit/Var(Y_c)`。
- **选择与检验严格分离**：conf 的选取（argmax 增量）与最强父集 T 的选取都只在 **search 分片**上做；audit 只算一次 p 值。否则就是赢家诅咒。

**假设与阈值**：检验 `H0: syn ≤ τ`，`t = (syn_audit − τ)/se`，单边 p 值用 t 分布（df = n_audit − 1）。**τ=0 的点零假设无筛选力**（order-3 有 57.5% 通过——"多一个字段总有一点信息"几乎恒真），τ 必须取审计关心的强度，主口径 **τ=0.10**。

**BH 程序**：标准 Benjamini–Hochberg，q=0.05；实现须自检——均匀零 p 值 5000 个 → 0 拒绝；掺 500 个强信号 → ≈541 拒绝（符合 5% FDR）。数学性质：FDR 清单必是硬阈值清单的真子集（只做减法）。

**基准结果**（order-3 全扫 13,244 个）：τ=0.10 硬阈值 1924 个 → 过 FDR 仅 **66 个（3.4%）**；通过者 top 的 syn_audit 0.461/0.440/0.431、se ≈0.03，与 82 号重训真值 0.455 互证。

## 3. 方法论红线：重训真值不得进查询路径

来源：`DNN_Aggresvation75_Correction/CHANGELOG.md` §2–3、§6（用户两次否决同构方案后确立）。

| 用途 | 判定 |
|---|---|
| 评估/验证论文主张（真值表作评测集、认证集、校准检验集） | **允许且必须**——唯一合法定论口径 |
| 第三层认证（管线末端对最终少数候选重训定论） | 允许（叫"认证"不叫"校准"） |
| 查询时的输入/修正：真值 m1/m2 做校准器特征、Apriori 用真值 syn2 剪枝、"低阶查表 + oracle 补高阶" | **禁止**——部署时数据持有方没有任何真值；塞进查询路径后"oracle 逼近得多准"变成不可证伪的空话（承认性检查实测：该类方案 89% 的效果来自真值查表本身） |
| 自校准（参照物 = 自家 K=200 估计，零真值） | 允许 |

三条操作性推论：① 提任何新方案先做**承认性检查**（把 oracle 拿掉、只留真值特征，看效果剩多少）；② oracle 在每一阶（含 |S|=1,2）都是唯一答题人，低阶真值表只用于"在可验证区间证实主张"；③ 70 号 Apriori 剪枝支线因此作废——且实测把真值移出查询路径后直接 oracle 扫三阶反而更强（无偏池保留 5% 召回 89% vs 26%）。

## 4. 87/90/93/94 修正链：最终站住的结论（以 94 号为准）

**修正链概要**：87（poly2 字典，"衰减律：三→四阶断崖 2.6×，密度衰减 150×"）→ 90（full 字典全量重扫 + 置换检验，"衰减律是字典假象，五阶强协同 24.7×"）→ 93（重训认证：**两个都错**——full 的 441 个 syn>0.2 认证后全假、与随机无差异 p=0.058；置换检验有结构盲点：打乱 Y 后 v(S) 与 v(T) 一起归零，查不出"两个都有信号时差分的系统性偏差"）→ 94（L1 自选 top 认证，给出第一个可靠答案）。

**站住的结论**（`DNN_Aggresvation94/outputs/decay_law_certified.csv`）：

| 阶 | 最强真值 | 口径 | 密度(syn>0.10) |
|---|---|---|---|
| 3 | **0.455** | 82 号专用 DNN 重训；FDR 配对检验独立给 0.461 互证 | **0.498%**（66 个过 FDR(τ=0.10,q=0.05)，统计保证计数） |
| 4 | **0.196** | 专用 DNN 重训（L1 自选 top-20，9 个 >0.10） | **≈0.069%** = 208 个 L1 估计 >0.10 × 精确率 9/20 ÷ C(44,4) |
| 5 | **0.154** | 专用 DNN 重训（L1 自选 top-21，10 个 >0.10） | **≈0.0051%** = 117 × 10/21 ÷ C(44,5) |

- **真值版衰减律**：强度 0.455 → 0.196 → 0.154（2.3× 再 1.3×，温和单调）；密度每升一阶约 7×/13×。既非 poly2 的断崖，也非 full 的"不衰减"。
- **密度估计方法（精确率校准）**：高阶密度 = 估计器超阈计数 × 认证精确率（top-K 中真值 >0.10 的比例）÷ 空间大小；三阶用 FDR 计数（有统计保证）。
- **反层级协同的认证级回答**：10 个已认证真五阶的最好四阶父集排名 164–2429，beam B=100 全漏、B=1000 漏 4/10、B=5000 全覆盖——反层级确实存在但幅度有限；**结论是 order≤5 全枚举（L1 查询 ~2.5ms，o5 全扫 10 分钟）而非加宽 beam，beam 弃用**，order≥6 标注开放问题。
- **搜索器裁决**：手工字典（poly2、full）在高阶上既报假又漏真；L1（闭式岭读出进训练回路的摊销表示）自选 top 显著为真（o4 p=0.013、o5 p=0.013/0.003），零 syn>0.2 假阳性。
- **跨 seed 秩一致性过滤**：3 个独立训练 seed，`cross_rank = √(rank_s1·rank_s2) ≤ 500` 过滤后 top 精确率 45%→100%、召回 9/9 不损失（真假候选跨 seed 排名分离 263×）。方法论要点：**对付摊销偏差要用独立重训的秩统计，不能用同族集成的方差**（84 号 σ 集成对强档失明）。
- **仍站住的 87/88 遗产**：抽样 GT 方法学（先在可全枚举的阶上验证抽样 CI 覆盖真值再外推）、遗漏上界证书（补集均匀抽样 + Clopper–Pearson 单侧 95% 上界，88 号 `miss_bound.py`，全枚举核验通过）、88 号三条严谨性修正本身（三分割/内部 val 早停/无放回等预算多 seed 随机基线）。
- **作废清单**：87 衰减律原数字、87 的 Wilson 区间用法（全枚举覆盖率是精确值）、88 不可能性论证（代理尾部假阳性）、90 "高阶风险被系统性低估"、90 的置换检验充分性主张。

## 5. 采样方案（73 号两段式 + 75 号测度改进的定稿）

**两段式子集失活采样**（oracle 训练时的掩码分布，73 号实证）：
- 每个训练样本：先抽保留字段数 `k ~ U{1,…,nG}`，再从 nG 个字段中无放回均匀抽 k 个；输入 `[x⊙m, m]`。
- 对照阶梯必报：`none`（恒满输入，= IGNN 式置零口径）与 `bern50`（Bernoulli(0.5)，尺寸集中在 nG/2、两端训练不足）。73 号结果：K=0 MAE 0.215/0.105/**0.060**（MLP），Spearman 0.734/0.900/**0.970**；GNN 侧结论一致。
- oracle 训练协议：EPOCHS 400 / PATIENCE 60 / BATCH 256 / Adam lr1e-3 wd5e-4 / 训练集内 15% 验证 / 数据切分 seed 42；**公平性设计：每个变体用自己的掩码分布做验证与早停**。

**75 号测度改进的最终定稿**：
- 试了 9 种尺寸分布 ×3 seed，**预注册判据**（跑前写死：扫描区 |S|≤3 MAE 降 ≥10% 且 >2σ；防护区 |S|≥13 退化 ≤0.010；协同 ρ +≥0.03）。结果落在"存在权衡"支。
- **U 形曲线**（反直觉主结论）：训练质量压在 |S|≤3 的最优占比在 **30–40%**（`logunif`：k≈exp(U(ln1,ln44))，扫描 −12.1%），照抄查询负载的 90% 版本反而退回基准——**训练分布不该照抄查询分布**。
- **最终方案（用户裁决）**：论文主线 = **单模型 `uniform` 两段式**；三路路由（|S|≤4 用 `logunif`、5–12 用 `uniform`、≥13 用 `large50`，阈值 t1=4/t2=12，全局 −11.0%±4.1%）只作为工程可选项报告。路由合法（|S| 是查询输入不是秘密）。
- 换数据集必带的复现闸门：`uniform` 须在旧评测集上复现基准数字（容差 ±0.008/±0.010/±0.010），不过就停下查 bug。
- 注意 75 号之后的演进：查询侧最终估计器已从"共享读出 + K 步微调"升级为 **L1**（91/93 号：同一两段式掩码采样器 + 反传穿过闭式岭 solve，λ 可学；掩码采样器与 75 号 `s_uniform` 逐项一致以保可比）。

**第二数据集复刻的最小管线**：① 两段式失活训 L1（3 seed）→ ② order≤5 全枚举扫描 + 跨 seed 秩过滤 → ③ top-K + 随机对照送专用 DNN 重训认证（88 号协议，单 seed、内部 val 早停、audit 只报一次）→ ④ 低阶全扫配对 t + BH-FDR(τ=0.10, q=0.05) 出统计保证清单 → ⑤ 高阶密度用"估计计数 × 认证精确率"报告。全程真值只出现在 ③④⑤ 的评估/认证端，绝不进 ①② 的查询路径。
