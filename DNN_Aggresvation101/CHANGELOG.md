# DNN_Aggresvation101 日志：独立认证（discovery / audit 不相交）

> 日期：2026-09-16。配置见 `base.yaml`，设计见 `WORKLOG.md`，运行日志 `logs/run101.log`。全部数值：`outputs/analysis/certify_all.csv`（逐次）、`certify_summary.csv` / `report101.md`（均值 ± 95% t 区间）。
> 图：[`figures/fig1_independent_certification.png`](figures/fig1_independent_certification.png)。

## 0. 一页结论

1. **max 操作的 winner's curse 真实存在，而且不只来自估计器**。同一份数据上用专用重训真值取最大，得到的 M 换到独立数据上会下降：PJM K=2 **0.051 ± 0.016**，CAISO 0.023 ± 0.013。⟹ 论文里报告的 M 数值应当用独立数据认证值，或至少标注这一偏差量级。
2. **估计器在 discovery 上给出的 M 偏高**：PJM K=1/2 为 +0.025/+0.017，CAISO +0.009/+0.008（区间含 0 的边缘）。同数据认证只比独立认证高 0.004–0.010。
3. **排序、档位和阈值结论在独立数据上基本保住**：
   - 估计器排序对 audit 真值 Kendall：PJM 0.73–0.74、CAISO 0.86；档位一致 78–88%；
   - τ=0.7、K=2 时 discovery 判定的跨越背景在 audit 上复现：PJM 80%、CAISO 90%；audit 真关键字段被找到：87% / 93%。
4. **强交互（I≥0.05）复现**：audit 上仍为正 CAISO 95%、PJM 71%；仍 >0.02 为 88% / 56%；audit 上的强交互被召回 92% / 76%。PJM 的交互在半数据上明显更噪。
5. **见证下界在半数据上变弱**：认证下界/真 M，PJM K=1 0.81、K=2 0.71；CAISO 0.94 / 0.88。召回（L≥M−0.02）PJM 50% / 25%，CAISO 73% / 44%。见证身份一致只有 12–37%。
6. **跨数据上界需要更保守的 α**：discovery 上校准、audit 上检验，α=0.05 覆盖 PJM 87–90%、CAISO 81%（低于名义）；**α=0.01 覆盖 94–97%**，紧度 PJM 0.11–0.12、CAISO 0.06。

## 2. 与 100 号（同表认证、全数据）的对比

| 认证下界 L/M（K=1 / K=2） | 100 号全数据·同表 | 101 号半数据·同表 | 101 号半数据·独立 |
| --- | --- | --- | --- |
| PJM L0ensx | 0.92 / 0.85 | 0.83 / 0.75 | 0.81 / 0.71 |
| CAISO L0ensx | 0.99 / 0.97 | 0.95 / 0.91 | 0.94 / 0.88 |
| 召回 PJM | 71% / 43% | 58% / 34% | 50% / 25% |
| 召回 CAISO | 98% / 88% | 82% / 59% | 73% / 44% |

两种因素分开后：**数据减半**使 L/M 下降约 0.04–0.10（第 1→2 列），**独立认证消除同表选择偏差**只再下降 0.01–0.04（第 2→3 列）。
所以估计器找见证这一步的 winner's curse 较小，全数据下的 100 号数值基本可信；但**真值层面**对 max 的偏差（K=2：PJM 0.05、CAISO 0.02）不可忽略，报告 M 数值时应当标注或使用独立数据认证值。
上界覆盖 α=0.05：100 号 PJM 95–96%、CAISO 97–98% → 101 号跨数据 PJM 87–90%、CAISO 81%（跨数据还叠加了两半之间真值本身的抽样差异）。

## 3. 局限

- 每半数据只有 PJM 2,294 / CAISO 3,052 行训练，数值不能与 100 号直接相减；
- 只用 L0ensx 一个估计器、DNN 一种真值攻击器；
- 3 次随机对半 × 2 方向（n=6）使区间较宽；时间块切分未做（按小时随机对半仍可能有时间相关性，使独立性偏乐观）。
