# DNN_Aggresvation124　字段风险画像：背景依赖的边际增益、背景放大量与危险背景

> **目的**：回到论文最初的问题——"背景会不会放大某个字段的风险、放大多少、在什么背景下放大"。
> 只用已有真值（111/112/116 号规模 ≤3，NEM 的规模 4 取自 119 号）与新主口径 E 的估计，CPU 分析，不重训。
> **定义**：Δ_i(T) = V(T∪i) − V(T)；M^(K) = max_{|T|≤K} Δ_i(T)；**背景放大量 Γ^(K) = M^(K) − M^(0)**（最坏背景相对单字段多出的风险）。

## 结论一：同一字段在不同背景下的边际增益差异很大，M 是这个分布的上包络（图 1B）

- 对每个 (字段, 目标)，把 Δ_i(T) 在全部规模 ≤2 的背景上画出来：分布很宽，最大值往往远离大多数背景。
- **平均背景增益（"平均语义"的代表，类似 Shapley/SAGE 的做法）中位数只有最大值的 32%**——平均会把背景放大稀释到约三分之一。
- 例：NEM PPCCGT 的"南澳风电预测"单独 0.187，平均背景增益 0.202，最坏背景下 0.603。

## 结论二：背景放大普遍存在（图 1A）

| | 10 个目标、264 个 (字段, 目标) |
| --- | --- |
| Γ^(1) 平均 | 0.082 |
| Γ^(2) 平均 | 0.110（单个最大 0.416） |
| Γ^(3) 平均 | 0.119 |
| 第一个背景字段贡献的放大比例 Γ^(1)/Γ^(2)（按总量） | 75% |
| Γ^(2)/Γ^(3)（按总量） | 93% |
| **单字段风险 < 0.3 而 Γ^(2) > 0.1 的 (字段, 目标)** | **91 / 264** |

放大最大的几个：NEM PPCCGT 南澳风电预测 0.19 → 0.60；CAISO 负荷 SP15 日前电能价 0.14 → 0.51；NEM PPCCGT 南澳可用容量 0.02 → 0.36。

## 结论三：K=1 的闭式在真值上精确成立

Γ^(1) = max(0, max_j I_ij)，I_ij = V(ij) − V(i) − V(j)：全部 264 个 (字段, 目标) 上误差为 0。
即 **K=1 时的背景放大量就是字段与最强伙伴之间的正协同**——这给"背景放大"一个直接的集合论解释。

## 结论四：危险背景往往"近等效"，共享一个核心伙伴字段

例：PPCCGT 的南澳风电预测，Top-5 背景的增益 0.545–0.603 几乎并列，且都含"南澳可用发电容量"。
所以解释输出宜给 Top-r 背景（或其共同的核心伙伴），而不是单一 argmax。

## 结论五：估计器对 Γ 与危险背景

| | 数值 |
| --- | --- |
| Γ^(2) 平均绝对误差（新主口径 E） | 0.017 |
| 真实最危险背景（精确同一集合）在估计器前 1 / 前 3 / 前 5 | 各目标 0.17–0.78 / 0.37–0.96 / 0.43–0.97 |
| 认证估计器前 3 个背景恢复的 Γ^(2) 总量 | **92.8%** |

"精确同一集合"的召回偏低主要因为结论四的近等效背景；按恢复的增益量算已经很高。
