# DNN_Aggresvation59 日志

## Modify by Codex: 2026-07-07

## 1. 子项目定位

把 DNN58 的 top-k 评估推进到 **重训忠实口径**:

```text
给定一个敏感度排名 r 和 k:
  取排名前 k 个 general 字段 S_k
  攻击者只使用 S_k 重新训练模型
  用重训后的 test R2 作为 v(S_k)
```

这样避免了 zero-mask 的分布外问题,也避免把 masked-trained oracle 的近似误差误当成真实泄露。

实验规模:

```text
5 个排名方法: dnn / noprior / static / zeromask / masked
2 个攻击者结构: dnn / gcn
11 个 k: 1,2,3,4,6,8,12,16,24,32,44
合计 5 x 2 x 11 = 110 次重训
```

调度器使用 4 GPU 并行,已完成所有任务。

## 2. 结果

### 2.1 五种排名在重训口径下差距很小

各 ranking 在 11 个 k 上的平均 R2:

| ranking | DNN 攻击者 | GCN 攻击者 |
|---|---:|---:|
| `dnn` | 0.7019 | 0.7135 |
| `noprior` | 0.6939 | 0.7062 |
| `static` | 0.7015 | 0.7074 |
| `zeromask` | 0.6942 | 0.7054 |
| `masked` | **0.7080** | **0.7179** |

`masked` 排名略高,但幅度不大。重训口径下,几条 top-k 曲线仍然高度接近,说明单字段排名问题本身区分度有限。

观察:

1. `zero-mask` 在小 k 严重低估泄露,到大 k 才接近 full-input 表现;
2. `masked` 近似在小 k 明显更接近重训,但高 k 仍会低估;
3. 真正可靠的 top-k 评价仍应优先使用重训口径。

## 3. 关键结论

1. **重训忠实口径下,五种单字段排名仍然拉不开。** 这说明瓶颈不在某个 attribution 算法没调好,而在"把泄露压缩成单字段排名"这个任务本身。
2. **masked ranking 有一点优势,但不足以单独构成主贡献。** 它改善了小子集排序,但优势不是压倒性的。
3. **zero-mask 不能作为小子集泄露真值。** 小 k 下它系统性低估,会导致错误的方法结论。
4. **DNN59 支持转向集合函数/协同泄露。** 后续主线应从 top-k 平均准确率转为 `v_c(S)`、二阶/高阶交互和最小防护集。

## 4. 意义与下一步

DNN59 是一个方法论收口:

```text
单字段归因曲线拉不开
  -> 不是因为 Shapley/mask/IG/LRP 都没做好
  -> 而是强边际字段主导了 top-k 任务
  -> 组合泄露和冗余/协同才是下一阶段要解释的结构
```

与 DNN56 的协同字段对结果合并后,可以形成更清晰的新方向:

- 用重训或摊销 oracle 定义 `v_c(S)`;
- 逐 confidential 分析,避免 12-conf 平均冲淡协同;
- 输出推断协同图,边表示 synergy/redundancy;
- 做排名式防护 vs 协同感知防护的对照实验。
