# DNN_Aggresvation103 日志：正式攻击器族真值 + 通用模型基线与消融

> 协议：[`paper/FINAL_PROTOCOL.md`](../paper/FINAL_PROTOCOL.md)。数值：`outputs/analysis/103_{A,B,C,D}.csv`、`report103.md`。图 4 张见 `figures/`。

## 0. 四条结论

1. **正式真值明显高于旧口径**：三攻击器取 max 后，V 比"仅多目标 DNN"高 0.009 / 0.018 / 0.027（PJM 规模 1/2/3）与 0.005 / 0.011 / 0.016（CAISO）。规模 3 上梯度提升树被选中 55%（PJM）/ 43%（CAISO），单目标 DNN 35% / 50%，多目标 DNN 仅 10% / 7%。**⟹ 100 号及更早的 M 数值系统性低估，正式结果一律用本号真值（K≤2）。**
2. **共享输出头必须换成集合特定闭式读出**（RQ-A2 核心）：PJM V-MAE 0.089 → 0.032，M^(2) MAE 0.118 → 0.032，见证召回 0.152 → 0.398。CAISO 同向。
3. **x,x² 旁路的增益在强真值下消失**：φ ridge 与 φ+x,x² 几乎相同（PJM V-MAE 0.0319 vs 0.0318，CAISO 0.0178 vs 0.0175）。这与 98/100 号在弱真值下的结论不同，正文应改述为"旁路不是必要成分"。
4. **掩码分布几乎不影响结果**（RQ-A3）：无掩码 / Bernoulli / uniform 的 M^(1) MAE 为 0.0298 / 0.0237 / 0.0254（PJM）、0.0111 / 0.0111 / 0.0107（CAISO）。**起决定作用的是集合特定的闭式读出，而不是预学习时的掩码采样分布。**

## 2. 按集合规模分层（RQ-A1）

V-MAE 随规模增长，但学出的 φ 把增长压住：PJM 规模 1→3，raw+x² 0.030→0.092、direct 0.033→0.091，而 φ+x,x²（集成）0.011→0.028；CAISO 0.024→0.069 / 0.027→0.072 对 0.007→0.016。

## 3. 效率（RQ-A5，k3 每集合查询）

见 `103_D.csv`：raw/raw2 约 0.5–1 ms，φ ridge 约 2–3 ms，φ+x,x² 约 4–6 ms，三种子集成约 27–37 ms，随机特征约 25 ms；single-target 折算到 12 目标为 46–60 ms。与 100 号的并行专用重训（56.6 / 74.3 ms 每集合 12 目标）对比结论不变。

## 4. 这些结果支持论文哪一句话

- 图1 → “共享表征 + 集合特定闭式读出”的必要性（RQ-A2），以及"学出的表征优于原始/随机特征"；
- 图2 → 掩码分布不是关键、元训练是可选增强、single-target 不必要（RQ-A3）；
- 图3 → 经验攻击能力必须由攻击器族定义（威胁模型严谨性）；
- 图4 → 通用模型在更大集合上仍然保持保真（RQ-A1）。

## 5. 局限

- CAISO 没有修复版元训练 φ（PJM 有 97 号 r93），元训练一列在 CAISO 缺失；
- K=3 需要规模 4 的真值，而规模 4 目前只有多目标 DNN + 树（无单目标 DNN），口径与 K≤2 不同，104 号会分别标注；
- 主估计器的选型用到了 test 上的 V-MAE（属于方法开发），最终安全结论由 106 号时间块独立认证兜底。
