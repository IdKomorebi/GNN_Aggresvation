# DNN_Aggresvation61 日志

## Modify by Claude: 2026-07-07

## 1. 子项目定位（方向切换：放弃集合敏感度，回到单点敏感度）

与 41-60 号的集合函数 / 协同泄露路线不同，本子项目开启新主线：
**纯数据驱动的单点敏感度**，动机来自 IGNN 论文（reports/ 下 TSG 2026）的三个缺陷：

1. 敏感度分数无操作语义（AHP 主观分被 GAT 平滑，0.83 不对应任何可测量的攻击效果）；
2. 相关系数建边 + 注意力扩散，传播规则不满足推断的基本规律（链式衰减、方向性）；
3. 需要专家打分与端到端训练，无标签场景不可用。

本方法立场：**攻击者只在乎可预测性**，不区分直接/间接依赖、不引入物理模型。
图的必然性来自链式推断——推断链就是图上的路径，成对度量表达不了多跳泄露。

## 2. 方法

三步，全部无监督、无标签、无专家输入：

1. **建边**（`src/edges.py`）：有向边权 w[i->j] = 单字段非线性回归器
   （HistGradientBoosting）用 i 预测 j 的测试集 R²，截断 [0,1]。
   含义 = "攻击者拿到 i 能把 j 猜到几成准"。只训 general 出边（机密节点吸收）。
2. **链敏感度**（`src/chain.py`）：链强度 = Π(边权) × α^(跳数-1)，α=0.8。
   - s_max(i) = 到任一机密字段的最强推断链强度（主指标，有界 [0,1]）；
   - s_or(i) = 对 12 个机密目标最强链的 noisy-OR 聚合暴露度；
   - s_walk(i) = 矩阵闭式对照 (I-αQ)^{-1}αR 行最大值（全路径强度和，仅排序对照）。
   实现：边成本 -ln(w·α)，Dijkstra 最短路 = 最强链，前驱数组回溯路径 → 泄露链清单。
3. **验证**（`src/validate.py`）：分数的定义就是可推断性，所以直接检验——
   用同一批成对模型模拟攻击者（只有成对关系、无联合数据）：
   直接攻击 R² 与两跳链式攻击 R²（ĵ=f_{i->j}(x_i)，ŷ=f_{j->c}(ĵ)），
   realized(i) = max_c max(直接, 最优两跳)。看各打分与 realized 的 Spearman，
   基线：s_1hop（只看一跳）、pearson_base（IGNN 式相关系数打分）。

数据与口径沿用 60 号：cleaned CSV（8760×61，12 个机密字段），shuffle 切分种子 42。

## 3. 结果（2026-07-07，耗时 1335s，其中链式攻击验证 21.4min）

数据实况：常量列再删 5 个，含 NaN 行 8760->6556，general=44 / confidential=12，
train=5244 / test=1312。

各打分与真实链式攻击成功率 realized_chained 的 Spearman：

| 打分 | rho | 说明 |
|---|---|---|
| s_1hop | +0.9994 | 一跳基线（见下方"近似恒等"说明） |
| **s_max（本方法主指标）** | **+0.9859** | 最强推断链 |
| pearson_base（IGNN 式） | +0.9461 | 相关系数打分 |
| s_or | +0.9347 | noisy-OR 聚合 |
| s_walk（矩阵扩散式） | +0.8646 | 谱半径>=1 需缩放 0.194，表现最差 |

三个关键发现：

1. **本数据集上多跳泄露实际不存在**：44 个字段无一例 realized_2hop 超过
   realized_direct 达 0.01 以上（最大增益 0.009，噪声级）。原因是数据处理不等式——
   攻击者拥有全部成对联合数据时，两跳链 f_jc(f_ij(x_i)) 不可能优于直接回归 f_ic(x_i)。
   因此 realized_chained ≡ realized_direct，s_1hop 的 0.9994 是**近似恒等式**而非胜利；
   一跳基线在此数据上"赢"是威胁模型使然，不是方法优劣的证据。
2. **s_max 显著优于 IGNN 式相关系数打分**（0.986 vs 0.946），且分数有操作语义
   （s_max=0.99 的 forecast_load 确实能以 R²=0.99 推出 metered_load）。
3. **矩阵扩散式 s_walk 表现最差**（0.865），且稠密强边导致谱半径>=1、级数发散需人为
   缩放——这正是"全路径求和的扩散式传播会过度计数"的实证，反过来支持了
   对 IGNN 类扩散方法的批评，最强链（max-product）语义比路径求和更合理。

敏感度排名 top5：forecast_load_mw_latest_available (0.991)、
forecast_load_mw_day_ahead (0.982)、system_energy_price_da (0.947)、
gen_fuel_gas_mw (0.875)、gen_fuel_nuclear_pct (0.866)。19/44 字段直接攻击 R²>0.5，
印证第 2 节末尾的担忧：RTO 级聚合字段耦合过强，一跳已捕获几乎全部泄露。

## 4. 已知限制 / 后续（关键：下一步做数据孤岛实验）

- **本数据无法展示图/链的必要性**（一跳已饱和）。要让多跳推断真正"咬合"，需要
  改威胁模型为**数据孤岛场景**：攻击者拿不到 (源字段, 机密字段) 的联合数据，
  只能拼接来自不同数据源的成对推断关系（如 silo A 有 (i,j)、silo B 有 (j,c)）。
  实验设计：遮蔽一部分 general->confidential 直接边（对攻击者和对我们的图同时遮蔽），
  此时链是唯一攻击路径，s_1hop 基线塌为 0，检验 s_max 是否仍能预测 realized 多跳攻击。
  这是证明"图不可替代"的实验，建议开 62 号做。
- 验证只做到两跳；三跳以上在本数据强度可忽略（α² 衰减 + R² 连乘）。
- α=0.8 未标定，可用 realized 攻击数据一维搜索反推。
- 链式攻击验证 21min 太慢（2 万余次 HGBR predict），孤岛实验前应先缓存
  中间预测 ĵ 复用，预计可降一个量级。
