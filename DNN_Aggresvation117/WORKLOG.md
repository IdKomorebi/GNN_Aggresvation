# DNN_Aggresvation117 工作日志

## 2026-09-24

- 第一版评测只有排序指标（AP、按分数扣留）。试跑发现 τ=0.5 时几乎全部字段都是关键字段，AP 退化，单字段 V({i}) 甚至略好于 M^(2)。
  这不是 M^(K) 的用途：它的价值在"关键性标记有定理保证""MUS 直接给出处置""随扣留相对重算"。于是补了决策与处置评测。
- 第一版扫描—认证按"最大边际"挑背景去确认越阈，召回很低（0.3–0.5）——挑错了对象：越阈要求背景自身 V(T) ≤ τ。
  改为在估计值上越过 τ−δ 的背景里取 V̂(T∪i) 最大的前 3 个去认证；并引入保守余量 δ 抵消估计器的共模低估。
- 扣留策略改成完全不用真值做选择（原版本的贪心用真值判断何时停止，不公平），真值只用来统计残余危险组合。
