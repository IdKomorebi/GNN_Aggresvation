## 二、推荐的新故事线：**集合敏感度审计的摊销边界**

### 一句话主张

> 把"任意可见字段集合的泄露风险"作为集合函数 $v_c(S)$ 来审计时，存在一条清晰的**摊销边界**：
> **绝大多数集合的敏感度可被单个共享模型以 O(1) 前向摊销到高精度；
> 但恰恰是风险最高的一类——强不可约协同——系统性地落在摊销能力之外；
> 而这一类又能被逐集合的闭式结构化求解器以毫秒代价恢复。**
> 因此正确的审计架构不是"再训一个更好的模型"，而是**分层**：
> 摊销负责覆盖与排序，逐集合求解负责最危险的少数，重训只做最终认证。

### 为什么这个故事强

1. **把所有负结果转成正贡献**：四次独立证伪不再是"我们失败了"，而是"我们刻画了边界"。
2. **有可证伪的机制**（任务稀释/干涉），并被四个不同方向的实验独立验证。
3. **有理论骨架**：摊销推断 vs 逐实例优化，是 ML 里的经典 tension（amortization gap），
   我们在一个真实安全任务上给出了它的**结构性刻画**，而不只是"gap 存在"。
4. **落点是可用协议**，不是一个模型。
5. **诚实**——而且诚实本身在安全类论文里是加分项。

### 叙事弧线（五幕）

| 幕 | 内容 | 支撑实验 |
|---|---|---|
| 1. 问题 | 风险由**集合**产生而非单字段（MW÷占比→总发电）；$2^{44}$ 不可穷举 | 现有 V4 引言（保留） |
| 2. 摊销可行 | 一个随机掩码 oracle 一次前向覆盖任意集合，大多数集合排序保真（ρ≈0.97） | 63/75 |
| 3. **边界**（核心） | 但对最强协同**系统性失明**：父集合估计塌陷到子集之下→增量为负→结构性漏检 | 80 |
| 4. **四次证伪** | 改采样(13变体)/加单调增量约束/任务级CVaR/显式二阶特征——**都改善平均，都修不好 tail** | 82/84/83/83 |
| 5. 出路 | 逐集合闭式结构化求解（ms级）恢复 tail；beam 解决高阶候选爆炸；衰减律界定问题边界 | 85/86/87 |

## 三、重构后的贡献清单（6 条）

1. **集合敏感度的形式化与摊销 oracle**
   合作博弈视角下 $v_c: 2^{V_g}\to[0,1]$，随机子集掩码训练把 $2^{44}$ 个攻击者最优响应摊销进一个模型。
   *（保留 V4 贡献 1，这条是好的。）*

2. **★摊销边界的定量刻画与机制**
   - 定量：K=0 时最强协同的父集合估计 $\hat v(ijk)$ **低于其二元子集**（0.159 < 0.178），
     导致 $\widehat{syn}_3<0$、排到全体后 3/4；
   - 机制：强协同 = 最复杂的算术电路 + 训练掩码中最低出现率（三特定字段同现约万分之几）
     → 共享参数的摊销回归不为其分配容量；
   - **"协同越强 ⟺ 电路越复杂 ⟺ 摊销越压制 ⟺ 越看不见"**（反直觉，且与"越强越易发现"的朴素预期相反）。

3. **★四个独立证伪：表示能力与任务摊薄是两个问题**
   | 干预 | 手段 | 结果 |
   |---|---|---|
   | 输入分布 | 13 种掩码 size 分布 + 掩码分组 | 平均 MAE 改善 ≤0.002，最强 tail **更差** |
   | 目标约束 | 单调性/增量一致性 hinge | 机械倒挂修好（负 S1: 10→0），**发现能力不变**；加大 λ 才抬强档但全局崩 |
   | 损失加权 | 任务级 CVaR（最难 q%） | 全面变差（自身 MSE 挖到的是噪声大的任务，不是被低估的任务） |
   | 表示能力 | 显式平方/乘积特征（poly2） | 普通父集合更准，最强 tail 仍失败 |
   **结论：这不是模型不够强，是"共享参数 + 任务平均"这一范式对最稀有任务的结构性限制。**

4. **★两个排序键的互补结构与"上界筛"的数学解释**
   - $v(ijk)=syn_3+\max_{pair}\ \ge syn_3$ ⟹ 按绝对泄露排序是 $syn_3$ 的**上界筛**（高召回、低精度）；
   - 实证：最强三阶三元组 **100% conf 错位**——让 $v$ 高的机密目标与真有三阶协同的目标**不是同一个**；
   - 这解释了为什么"取绝对值大"这个看似朴素的启发式能救最强档，也解释了它为何不能当主筛。

5. **★逐集合闭式结构化求解 + 非枚举高阶搜索 + 覆盖率证书**
   - 算术字典（raw/平方/两两积/安全比值）+ 充分统计量缓存 → 单次 $\hat v(S)$ **ms 级**，
     全 946 pair + 13244 triple **5 秒**；在最强协同上超过 K50 微调（Top-30% 召回 0.963 vs 0.911）；
   - beam（**增量键**，非上界键）解决候选爆炸：整条 order-2→8 搜索 **265 秒**，
     而单 order-8 全枚举需约 **8.5 天**（~2800×）；
   - **覆盖率证书**：Wilson 95% 下界 + 逆查表（"要 95% 置信下界 ≥0.8 的强四阶覆盖，需 22.8% 枚举成本"）。

6. **★纯高阶协同的衰减律（界定问题本身的边界）**
   - **强度断崖**：三阶 max $syn$=0.472 → 四阶 0.180，四阶以上一律 ≤0.19 ⟹ **最危险的不可约协同在低阶**；
   - **密度指数衰减**：3.14% → 0.169% → 0.0102% → 0.0040% → 0.0020% → <0.0077%(95%上界)；
   - **但绝对数量因空间爆炸未必减少**（order-7 估计仍有 ~766 个 $syn>0.10$）；
   - 方法学：高阶不可枚举时用**均匀抽样作无偏 GT**，并**先在 order-4 用全枚举验证抽样可信**
     （三阈值 CI 全部覆盖真值）。

> 这条第 6 是**全篇的收束**：我们不仅给方法，还回答了"这个问题到底有多大"。
