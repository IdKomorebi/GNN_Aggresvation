## 演示操作

- `←` / `→`、`PageUp` / `PageDown` 或空格：翻页。
- `Home` / `End`：首页 / 末页。
- `F`：全屏；也可以使用浏览器的全屏功能。
- `O`：显示页码总览，点击跳转。
- `N`：查看当前页的讲述提示和原始来源；`Esc` 关闭。
- 底部滑块可直接选择页码，网址末尾 `#页码` 可定位到指定页。
- 手机支持左右滑动，横屏更适合阅读。
- “打印 / PDF”可以输出全部幻灯片。打印时关闭浏览器页眉页脚，启用背景图形；优先使用 Chrome / Edge。

讲稿抽屉显示在当前演示窗口，投影时按需打开。准备口头汇报可直接阅读 [讲稿](讲稿/) 目录中的六份 Markdown。未设置固定播放时间或自动翻页。

## 图表与来源

45 张实验图全部按既有结果表或明确标注的实验日志重新绘制，使用矢量图、数值标签、关键区域底色和错位标注。另绘制 9 张流程／原理示意图。未运行新的训练或科学实验。

- [逐页来源与统计口径](数据与图表来源.md)
- `assets/figure_manifest.json`：绘图数据、源文件与统计说明。
- `assets/source_manifest.json`：所引用源文件的路径与 SHA-256。
- `assets/figures/`：可独立使用的 SVG 图表。
- `assets/previews/`：逐页预览和每份汇报的总览图。
- `assets/presentation_validation.json`：实际浏览器排版和交互检查。

阶段结果使用当时配置；最终估计器的结果以 125、126、127 为准。全表与抽样、独立审计与同表验证、单模型与三模型、十目标与阶段十一目标均作区分。不把所有阶段图表更新成最终数值，以保留真实的修改过程。

六份 HTML 可以单独复制后离线展示；“返回目录”和原始来源链接需要保留目录结构。页面使用系统中文字体，实验图的文字已转成矢量路径。
