## 核心结论

1. **南网现行分级只看数据本身。** 它回答“这份数据泄露了有多严重”，没有回答“发出去之后和接收方已有的数据合起来能推出什么”。后者在南网文件里已经被提出（从严性原则、“深度”要素、附录 D/E、风险评估第 382 项、披露细则 7.3），但没有给出方法和阈值。
2. **体系分三层，只加输入、不改规则。** 规则层照用南网的五级表、判定矩阵和流程；证据层新增推断证据（关联初筛 → 集合扫描 → 重训认证）；决策层通过“推断继承”（字段若补上某敏感目标的最后一块拼图，就继承该目标的等级，取最大）接回南网矩阵，并通过风险评级接回风险评估矩阵。
3. **各部分的分工。** 师兄论文负责入口和骨架：关联图、规则抽取、共现挖掘、动态调整，其中强化学习移到处置层。近期研究负责判定和证据：V、M^(K)、见证背景、关键性定理、扫描—认证。南网文件负责约束和语境：等级、矩阵、角色、时点。披露细则的“公众/公开/特定 + 预测/出清/运行”直接给出了攻击者的公开基底。
