## 相对 V3 的变化

- 立场改为项目组向南网汇报：不区分方法来源，不标注论文出处，去掉“原体系与本框架”对照页和来源图例。
- 标题与小标题改为平实的名词短语。
- 南网依据前置并就地标注：新增“编制依据”页定义《分级手册》《风评手册》《开放目录》《披露细则》《注册细则》五个简称；框架图右栏、各方法页页脚、表格的“依据”列都标了条款；末尾保留一页对应关系小结。
- 体系框架与关键方法一一对应：框架图的步骤编号与方法页的小标题相同。
- 补充了度量定义页（集合推断能力 V、边际推断增益、M(0)、M(K)、Γ(K)、泄露判定线）、等级一致性条件和等级优化模型的表达式。
- 去掉了算例页。
