中文字体使用 Noto Sans CJK SC，SVG 配置 Microsoft YaHei 为回退字体。跨电脑查看固定版式时可使用 PDF；编辑 PPT 时建议安装同名字体。

## 重建

在本目录运行：

```bash
python src/build_deck.py
NODE_PATH=/data1/duhaocun/envs/node_pptx_work/node_modules /data1/duhaocun/envs/node_pptx/bin/node src/build_ppt.js
python src/render_svg.py
```

PDF 由 LibreOffice 从 PPT 转换，`preview/` 再从该 PDF 渲染。PPT 和 SVG 共用 `src/scenes.json`，避免内容与排版分别维护产生差异。

本次复核了现有材料和结果，没有重新运行模型实验，也没有使用南网实际数据开展定级。南网条款按所供稿状态引用；内容中的原理示意与已有研究结果已分别标明。
