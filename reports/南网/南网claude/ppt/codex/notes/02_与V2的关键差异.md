# 与 V2 的关键差异及采用理由

本文件用于组内核对，不放入面向甲方的主讲页。用户已明确要求重点展示 GRPO；新版保留其研究位置，同时修正不受材料支持的连接关系。

## 1. 先统一 V2 与最新实验的版本

V2 README 已记录 E1–E3 和 E2b 完成，但 V2 主文档及 PPT 仍存在“尚未实验”“验证进行中”等旧表述。新版使用 `../../../实验/01_等级一致性优化/WORKLOG.md` 对应的 2026-10-07 结果，具体数据核对以实验 CSV 为准。

- 当前规模的整数规划是必要精确基线；不能宣称 GRPO 比它更好或是唯一可用方法。
- GRPO + 回退在已有两种子设置中不劣于覆盖贪心，但优势小。主讲展示它的机制，备查页披露比较结果。
- 一次性“前 3 个背景认证”不足以支撑等级方案无残余；新版采用建议与补充验证交替更新的闭环。

## 2. 等级与授权不是同一个变量

V2 用角色上限 c 和字段级别比较来生成可见范围。这是适合实验的简化假设，不是所有市场业务的实际权限模型。实际场景还涉及具体主体、披露类别、用途、时点、合同与历史提供。

新版保留该假设下的联合定级研究，但先要求确认等级—可得范围映射；主讲明确“已经掌握的数据不能通过改级收回”。可见范围不随级别改变、历史背景已暴露或所有相关字段必须提供时，可以没有可行调整方案，不能宣称“一定有解”。这些情况输出冲突与复核任务。

## 3. 依法披露不等于安全等级永久锁定

需要固定的是已知背景和适用的披露义务。是否允许改变正式等级，仍取决于有效规则、对象和程序。新版不写“所有依法公开字段一律等级锁定”，也不把“运行日次日披露”泛化为所有运行信息都向社会公众公开。

## 4. 越线不等于自动继承目标等级

较高的经验推断精度可以触发复核，却不能单独决定影响程度或使所有输入字段自动继承目标级别。对数据集、衍生产品、单字段分别判断对象、深度和后果，回到影响矩阵。联合优化在已认可的候选级别与约束内比较方案；最小代价结果本身不是法定级别的依据。

## 5. 几个量各司其职

- V：经验评估协议下，给定字段集合对目标的样本外推断能力。
- M：字段在背景中的最大增量，用于定位、解释和组成状态。
- Γ：相对无额外背景的放大量。
- 约束：检查组合的最终 V 是否越过业务确认的复核线，不能只检查 M。
- τ 和 K：分别是评估阈值与搜索预算，不是法规规定的等级阈值或攻击者能力上界。

因此不采用“优先调整 M 最大的字段”等同最优定级的说法。关联图也不作为联合扫描的硬筛选器。

## 6. 已有验证的实际含义

E2b 的“重训验证”是查询已有专用重训真值表；本次并未新增南网数据训练。其零残余只针对固定数据、模型评估口径以及最多 3 个字段的组合范围；约 39% 与 83% 是验证集合比例，不是现场耗时。规则等级与代价是随机生成的。新版将这些边界放在备查页与备注中。

## 7. 视觉与叙事

V2 的“三版对照”和个人方法归属撤出甲方 PPT；替换为“问题—体系—原理—求解—输出”的统一叙事。全套白底，深色文字，蓝色表示规则与级别，青绿色表示推断证据，琥珀色只标记需复核或受约束的部分。所有主图重新画为矢量，PPT 文字和图形可编辑。
