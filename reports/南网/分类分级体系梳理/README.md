## 三个核心判断

1. 南网手册采用三类基础等级、1—5 级；论文四档动作不能原样转用，需要区分正式等级与保护动作。
2. 近期研究适合提供背景组合推断证据，直接支撑风险评估第 382 项及衍生/聚合复评；推断分数不直接等于正式级别。
3. 目录共 561 项，其中 548 项有条件开放、13 项无条件开放，且没有逐项安全等级列。主体、用途、时点、粒度与已知背景必须一起进入评估。
