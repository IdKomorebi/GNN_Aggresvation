## 重新编译

```bash
cd reports/组会claude/01_字段风险怎么定义/V3 && tectonic report.tex
```

新增图片时，先把原图复制到 `figures/`（任意文件名），在 `report.tex` 中用 `\fig{figures/文件名}{图题}` 引用，然后运行：

```bash
/data1/duhaocun/miniconda3/envs/Pytorch310_codex/bin/python reports/组会claude/_tools/finalize.py reports/组会claude/<文件夹>/<版本>
```

脚本会按正文顺序把图重命名为 图1、图2……，用文件哈希找回原图路径并写进图题和 `图片来源.md`。
