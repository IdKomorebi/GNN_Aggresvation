## 结论先行

1. **理论层已经可以定稿**：
   - M^(K) 是条件评价函数 v_B(T)=V(B∪T)−V(B) 上的背景预算约束 MCI；
   - v1 中三处过强命题已由反例推翻并改写；
   - 带基底的恒等式、截断预算、通用余量、关键性等价都经过证明和随机博弈核验。
2. **实验层的主要结论在两个数据集、两类攻击器、独立数据上基本成立**：
   - 单字段分析会系统性低估组合风险（相对单字段升档 35–71%）；
   - 低阶背景捕获绝大部分最坏风险（K=2 相对已认证 MCI 下界 PJM 0.88、CAISO 0.93；K=3 ≈1.0）；
   - 字段排序与档位对攻击器、种子、独立数据基本稳定。
3. **最大风险在主线的"组成一"**：在 41 个字段上，**GPU 并行专用重训 11 分钟就能精确算完 K=2**，通用模型不是必需的；它的优势只在 K=3、MCI 搜索、更大字段数、反复更换基底/数据时才实质。按"通用模型让 M^(K) 可计算"写贡献，会被审稿人用本报告的效率表直接反驳。**必须重新定位通用模型**，见第 9–10 节。
4. **目前还不够投稿**。缺的不是指标，而是：
   - 通用模型必要性的正面证据（大字段或多场景复用）；
   - 与电力领域基线（相关性/单字段准确率/IGNN）的分级效果对比；
   - 分级表如何用于发布决策的完整示例。

## 1. 当前 M^(K) 理论：哪些严格正确，哪些已修改

| 命题 | 状态 | 说明 |
| --- | --- | --- |
| M^(K) 与 MCI 的关系 | ✅ 严格（新增命题 3.1） | v_B 单调、v_B(∅)=0，满足 Catav 假设；B=∅ 时为截断 MCI，K ≥ \|H\|−1 时等于 MCI |
| K=1 闭式 | ✅ 已改为带基底写法 | M^(0)=a_i^B=V(B∪i)−V(B)；M^(1)=a_i^B+max(0,max_j I_ij^B)，I^B=V(B∪ij)−V(B∪i)−V(B∪j)+V(B)。3000 个随机 4 人博弈零违例 |
| 截断预算 V(B∪A)−V(B) ≤ Σ M_i^(K)（\|A\|≤K+1） | ✅ 严格 | 只需 v_B(∅)=0，不需单调；逐阶预算更紧 |
| 余量 | ⚠ **已修改量词** | M 是"对所有 τ 同时成立"的最小余量，等价于统一边际界；**固定 τ 的最小余量可以严格更小**（例：M=0.4、τ=0.95 时为 0） |
| 关键性 ⇔ 属于 ≤K+1 的最小不安全集合 | ✅ 严格，**需要单调** | 已给出非单调反例；实证上闭包前 0.2% 不一致，闭包后 0 |
| "增强为 0 ⇔ 次模" | ❌ **过强，已删改** | 反例：3 人单调博弈，所有字段 M^(n−1)=a，但 v 非次模。现为"增强为 0 ⇔ 相对空背景无放大"，严格弱于次模 |
| "k 阶协同强度 s ⇒ 成员 M^(k−1) ≥ s" | ⚠ **已限定** | 强度为不可约增益 syn(S) 时成立（20000 个博弈零违例）；为 Möbius 红利时不成立（m=1.0 > M=0.5），已删除该版本 |
| 三层对象 V\*/V_retrain/V_amortized | ✅ 已采用 | 单调闭包定义为"经验攻击能力的闭包"（val 上选子集、test 上报告），不再当作风险定义本身；闭包不破坏 M^(K) 的局部性 |
| 估计误差传播 | ✅ 新增命题 7 | \|M̃−M\| ≤ max\|Δ̃−Δ\| ≤ 2 max\|Ṽ−V\|；独立认证下界 L=Δ(T̃) ≤ M；按见证类边际误差分位构造上界 U |

## 2. 哪些性质已由 Catav MCI 给出，不能算本文创新

逐页核对 PMLR 版原文（Catav et al., ICML 2021）：
- MCI 定义：所有背景（含空集）上的最大边际；ν 单调、ν(∅)=0 的假设；
- 三条公理（marginal contribution、elimination、minimalism）与唯一性定理；
- 单字段下界、super-efficiency、duplication invariance、dummy、对称、次可加；
- context 概念（即本文的见证背景）；
- **Shapley 在相关/重复特征下低估**，以及"复制特征后 Shapley 下降"的例子；
- 采样给下界、分支定界给上界、有限样本一致收敛。

本文 v1 中"复制不变""单字段下界""见证""Shapley 被副本稀释"都属于此列，**v2 已移入"继承"栏**。

## 3. M^(K) 相比 MCI 真正新增的内容

**理论**
- 攻击者背景预算 K 与公开基底 B 的威胁模型参数化（条件评价函数 + 截断）；
- 截断 super-efficiency 与逐阶预算：比 super-efficiency 更强，不是其推论；
- 通用安全余量刻画，并区分固定阈值余量；
- τ-关键 ⇔ 属于 ≤K+1 的最小不安全集合（把字段量与集合级安全对象联系起来）；
- 带基底 K=1 闭式（交互只用于解释升档）；
- 在摊销估计器上的误差传播与 L≤M≤U 构造。

**经验**
- 完整字段集上的 K 饱和与协同阶测量；
- 攻击器族、基底对字段分级的影响；
- 独立数据认证下的选择偏差量级。

## 4. 44 字段 K=2 是否实际可行

**可行，而且可以精确计算，不需要抽样或通用模型。**
- 去别名后两数据集各 41 个字段，规模 ≤4 的全部 112,791 个集合（支持 K≤3），并行专用重训三卡用时 PJM 约 36 分钟、CAISO 约 48 分钟；
- K=2 只需规模 ≤3 的 11,521 个集合，单卡 PJM 11 分钟、CAISO 14 分钟。

（100 号 §6、图7）

## 5. "K=2 达到约 92% 饱和"是否复现

以"通用模型搜索大背景 + 专用重训认证"得到的 MCI 已认证下界为分母（所以饱和比是上估）：

| | K=1 | K=2 | K=3 |
| --- | --- | --- | --- |
| PJM 平均 / 中位 | 0.71 / 0.75 | **0.88 / 0.93** | 0.999 |
| CAISO 平均 / 中位 | 0.81 / 0.85 | **0.93 / 0.97** | 0.999 |

- **CAISO 复现，PJM 略低**。K=3 在两数据集上基本饱和；
- 1,968 个认证过的大背景（平均 5–5.5 个字段）只有 0.2% 超过 M^(3) 0.02。
- 小博弈上的数字偏高有解释：候选字段越多，M^(K) 不减（命题 5b，全集比小博弈 K=2 高 0.037），所以饱和比必然下降。
- 建议**不预设 K=2**：主表同时报告升级曲线 (M^0, M^1, M^2, M^3)，并说明 K=3 在本数据上已饱和。

（100 号 §2–3、图1–2）

## 6. worst-background 能否给出可靠上下界

- **K≤2 基本可以**。全数据、留一字段交叉校准：
  - 上界 α=0.05 覆盖 92–98%，紧度 PJM 0.04–0.06、CAISO 0.02；
  - 下界（估计器见证的专用重训边际）/真 M：PJM K=1 0.92–0.96、K=2 0.85–0.91，CAISO 0.97–0.99。
- **K=3 不行**：上界覆盖 84–93%，低于名义；PJM 见证召回 35–43%。
- **边际误差**：PJM MAE 0.014、q99 0.08、最大 0.41；CAISO 0.0075、0.047、0.27。强边际层的低估略大（PJM q95 0.06）。
- **最好的价值估计器不等于最好的 M 估计器**：PJM 上 L0ensx 价值最准，但 M 正偏 +0.02、K=2 召回 43%；L1x 召回 62%。

（100 号 §4、图4–5）

## 7. 独立认证后原结论是否仍成立

discovery / audit 完全不相交，3 次随机对半 × 2 方向：

- **仍成立**：
  - 排序（Kendall PJM 0.73–0.74、CAISO 0.86）、档位一致 78–88%；
  - τ=0.7 跨越背景在 audit 上复现 80–93%，关键字段召回 85–94%；
  - 强交互在 audit 上仍为正：CAISO 95%、PJM 71%。
- **需要修正**：
  - 真值层面的 max 选择偏差不可忽略：K=2 时 PJM 0.051±0.016、CAISO 0.023±0.013 ⟹ 报告 M 数值应标注或使用独立认证值；
  - 跨数据上界要用 α=0.01 才能达到 94–97% 覆盖。
- **分解**：数据减半使认证下界下降 0.04–0.10，独立认证再降 0.01–0.04 ⟹ 估计器找见证这一步的 winner's curse 较小。

（101 号 CHANGELOG、图1）

## 8. 多攻击器以后 M 是否稳定

DNN ∪ 梯度提升树（sklearn HistGBDT；XGBoost/LightGBM 环境未装，未做）：

- **稳定的**：
  - 树模型在规模 2–3 的集合上胜过 DNN 48–69%；
  - M 上移 0.01–0.03（PJM）/ 0.007–0.015（CAISO）；
  - 排序 Kendall 0.82–0.94、档位一致 87–97%。
- **不稳定的**：
  - 见证身份（K=2 一致 31–40%，种子之间也只有 58–63%）⟹ 存在多个近等效最坏背景，应当报告见证达到的边际而不是身份；
  - **PJM 阈值跨越**：τ=0.7、K=2 的关键字段数 220→334 ⟹ 经验攻击能力必须按攻击器族取最大，结论应声明攻击器族。

（100 号 §2、图3）

## 10. 按主线，现在是否足够投稿，还缺什么

**判断：理论与核心实验足够支撑一篇方法论文的主体，但还不能投稿。** 缺口按优先级：

1. **通用模型的必要性（P0）**。41 字段 K≤2 上并行重训 11 分钟即可精确计算，这会直接动摇"组成一"。可选路线：
   - (a) **加入真正需要摊销的场景并实测**：更大字段集（CAISO 原始 bundle 列更多，或多节点/多区域数据，p≥100）、多基底/多数据快照复用、交互式审查；报告通用模型 + 少量重训认证的**总成本与漏判**，对比全量并行重训；
   - (b) **改为混合流程作为方法**：通用模型给 L≤M≤U，只对区间跨越阈值的字段做专用重训认证，报告"需要认证的字段比例 × 节省的重训次数 × 分级错误率"；
   - (c) **把并行专用重训本身写成计算贡献**，通用模型降为扩展工具。

   我倾向 (b)+(a)：方法上自然，也回应了"通用模型误差是否影响分级"。
2. **领域基线对比（P0）**：单字段相关性/NMI、单字段准确率、IGNN（或依文意构造的图敏感度排序）。在"找出组合高风险字段"这一任务上与 M^(K) 对比，指标用 τ-关键字段召回、档位一致、扣留后剩余风险。目前只有 M^(0)（单字段）与 Shapley/SAGE 的对照。
3. **分级表与发布决策示例（P1）**：给出一个目标、一个公开基底下的分级表（a、M^1、M^2、见证、认证值、档位），以及用逐阶预算快速放行的发布审查示例；阈值 τ 与档位的业务依据需要说明。
4. **攻击器族（P1）**：补 XGBoost/LightGBM（需在不改动现有 conda 环境的前提下安装到项目本地目录）或 Random Forest，至少在规模 ≤3 上复核阈值跨越。
5. **时间块独立认证（P2）**：101 号是按小时随机对半，时间相关性可能使独立性偏乐观；补一个按月份分块的 discovery/audit。
6. **目标副本与字段口径（P2）**：PJM 目标副本已剔除、CAISO 未发现；论文中需给出字段清单与去别名规则表。

**不建议再做**：新的交互指标、Shapley 方法扩展、高阶协同搜索、单调正则。
